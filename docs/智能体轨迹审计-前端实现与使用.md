# 智能体轨迹审计前端实现与使用

## 页面入口

启动项目 `npm run dev`，进入 `/compliance/agent-traces`。使用全链路合规治理原有的“示例演示／真实接口”开关切换运行方式。页面没有第二套独立模式开关；真实接口错误不会退回演示数据。

本次所有代码、文档、验证脚本和截图都位于 ContentSecurityVue。未改后端、LLM 工程及外部 doc 原始说明。保留开发前已有的 `.env.production.local` 和 `package-lock.json` 改动。

## 实现内容

- 新增合规顶级子页，不覆盖旧推理审计、平台溯源或风险审计接口。
- 三张格式卡片、格式样例复制／下载、批次创建、多文件上传、批量绑定、逐文件格式覆盖和解析任务。
- 批次汇总、测试集标签、来源／当前批次／当前样本选择、样本查询与分页、相邻样本跨页导航。
- 原始只读文本与标准化事件、事件目录、当前来源字段映射、问题定位、数据完整性与用量覆盖率。
- 统计指标提供批次真实聚合和类别分布；思维路径提供已记录事件列表；工具交互提供过滤后的调用／返回目录和输入输出详情。这三个视图为可用的基础分析页，不宣称已复刻其他复杂设计图。
- 当前视图 PNG 与结果包任务、状态查询、下载票据和真实字节下载。HTTP 图像导出由后端声明渲染器可用性；未支持项禁用。Mock 生成合法 PNG 和 ZIP，本地报告采用摘要画布，用户原始参数不进入默认脱敏包。

## 演示步骤

1. 打开页面并切到示例演示，看到 2 文件、200 轨迹、3 种支持格式、2 种已接入格式。
2. 按来源、批次、样本切换；默认示例 AUD-0042 为英文，18 步、7 次调用。
3. 选预览内部事件，观察标准化字段与原始定位；使用下一条验证跨样本导航。
4. 点击时间／用量问题的定位样本，进入批次问题集合；清除问题标签可返回普通范围。
5. 下载格式样例，创建新批次，选择样例文件上传，开始解析，观察任务 pending／running／succeeded；不含时间和用量的样例会出现非阻塞缺失提示。
6. JSONL 可混合合法与坏记录，验证部分成功和失败行号。手动格式不匹配会报错，不返回随机成功。
7. 结果包生成完成后点击任务栏下载，关闭弹窗不取消作业。

## 关键口径与约束

汇总和底部校验为整个批次；来源只过滤预览。时间 192/200 和用量 160/200 是字段可用性，不是风险比例或推理摘要。调用关联按适用轨迹汇总，无调用轨迹不适用。失败记录与成功轨迹使用不同单位。

原文、任意参数和输出通过字符串传输，避免平台递归 mapKeys 改写证据。页面不用 v-html 渲染日志。样例刷新后恢复初始数据，不是真实审计持久化；Mock 内部 ID 有 mock_ 前缀。

Mock 支持文档给出的三种最小结构，不宣称兼容所有供应商导出版本；上传文件单个上限 5 MiB、一次 10 个，逐个上传以限制浏览器占用。后端模式以 uploadPolicy 为准。Mock 任务随轮询推进，页面刷新会恢复样例；真实任务由服务端持久化。

## 验证方式

```text
npm run build
npx vitest run src/api/agent-traces.test.ts src/mock/agent-traces.test.ts src/stores/agent-traces.test.ts src/api/compliance.test.ts src/stores/compliance.test.ts
npx eslint src/types/agent-traces.ts src/api/agent-traces.ts src/utils/agent-trace-export.ts src/mock/agent-traces.ts src/stores/agent-traces.ts src/views/compliance/AgentTraceAuditPage.vue
node scripts/agent-traces-browser-check.cjs
```

浏览器脚本需要 Playwright 与本机 Edge，支持 `PLAYWRIGHT_MODULE` 指向已安装模块；脚本临时使用 1225 端口并在结束后关闭。结果放在 `docs/agent-traces-verification`。全项目 lint 开发前已有两项错误：model-workbench.ts 未使用的 PageResult，TrainingPage.vue 的 computed 使用错误；不通过修改无关模块掩盖基线问题。
