# 智能体轨迹审计统计指标：后端接入手册

版本：statistics_v1；更新：2026-11-07。

本文对应已经接入前端的“统计指标 + 样本 JSON 抽屉”。后端可直接按本文与附带 JSON 样例实现。前端入口为 `/compliance/agent-traces?view=statistics`。本次未修改后端项目；下列新领域能力仍需后端实现、部署和联调。

## 1. 先实现哪些接口

所有路径省略公共前缀 `/api/v1`。

| 编号 | 方法 / 路径 | 用途与调用时机 |
| --- | --- | --- |
| S01 | GET `/compliance/agent-traces/statistics` | 一次返回选项、8项KPI、所有图表、完整性、列表数量、初始页、权限与导出能力；首次和主查询调用 |
| S02 | GET `/compliance/agent-traces/batches/{batch_id}/samples` | 当前列表子集分页，始终显式 `view=statistics` |
| S03 | GET `/compliance/agent-traces/batches/{batch_id}/samples/{trace_id}` | 单样本摘要、JSON、原始片段、映射、邻居；始终 `view=statistics` |
| S04 | POST `/tasks/execute` | 平台任务能力 `agent_trace_export`；PNG / ZIP / 单样本 JSON |
| S05 | GET `/tasks/{task_id}` | 平台任务状态、进度和产物 |
| S06 | POST `/compliance/agent-traces/artifacts/{artifact_id}/download-tickets` | 已就绪产物的授权下载票据 |

只有 S01 是新统计聚合 URL。S02、S03、S06 沿用接入页的资源，S04、S05 复用平台任务，不按每个 KPI/每条记录创建新端点。旧客户端不传 `view=statistics` 时保持接入页原响应，不删除原字段。

建议联调顺序：S01 → S02 → S03 → S04/S05/S06。服务未支持某导出种类时，在 S01 明确 `availability=unavailable` 和原因。

## 2. 平台协议不能更改

请求器：`src/api/request.ts`。业务适配器：`src/api/agent-trace-statistics.ts`。类型定义：`src/types/agent-trace-statistics.ts`。

请求/响应网络字段使用 snake_case；前端公共层转换 camelCase 并解包 `data`，业务组件不会再次解包。公共认证采用 Bearer，携带 X-Request-Id，可能携带 X-Trace-Id；沿用平台租户、身份、授权和401流程。

```json
{"code":0,"message":"ok","data":{},"trace_id":"http_request_trace","timestamp":"2026-11-07T12:00:00+08:00"}
```

`envelope.trace_id` 是 HTTP 追踪号；`data.trace_id` 是样本业务标识。不能混用。不要把200、401、403、404、422都包装成成功 `code=0`；非成功也返回可读中文 `message`。不要返回前端无法解包的204。

**任意源 JSON 必须使用文本字段传输。** `json_text`、`raw_text`、`input_json`、`output_json` 字符串内部的 `User_ID`、`tool_call_id` 等不会经过键名转换。不能直接把任意日志对象嵌进 DTO 后期待保真，也不能要求前端改共享 mapKeys。

计数/Token 为安全范围内非负整数；毫秒为 `duration_ms`；时间戳带时区。缺失用 null，真实0保留0。百分比值为0—100，比值为数值，例如1.58，不要预拼中文单位。

## 3. 快照与查询上下文

主范围 B：授权操作者/租户 + batch_id + snapshot_id + projection_version + language。

八项 KPI、图表、完整性和 list_counts 全属于 B。统计投影与快照固定不变；审计结果改变时发布新投影，旧版本不存在返回410，不悄悄换新数据。

列表范围 L = B + list_filter：

- `all`：全部已解析样本。
- `risk`：`audit_decision=risk_found` 的样本ID去重。
- `missing_fields`：source/time/reasoning 中缺失或无效的样本ID并集。

风险和缺失可以交叉。不要将类别标签当风险判定，不要将缺失数相加。排序固定 `ingest_order_asc_trace_id_asc`；内部 ID 与 AUD 展示编号分开。前端不以编号加减计算邻居。

context 必须回显：`batch_id,snapshot_id,projection_version,language,list_filter,page_size,sort,filter_fingerprint`。前端会验证身份、语言、筛选与分页，错配响应将被拒绝。

## 4. S01：一次返回整个首屏

### 参数

| 参数 | 规则 |
| --- | --- |
| batch_id | 可省略，由后端选择最近可访问且已发布批次；显式给定错误时不得换别的批次 |
| snapshot_id | 可省略取当前批次 active snapshot；后续 S02/S03/S04 固定传回 |
| projection_version | 可省略，解析并固定当前可用版本 |
| language | all/zh/en/other/unknown，默认all |
| list_filter | all/risk/missing_fields，默认all，仅影响初始列表 |
| page,page_size | 默认1/6，最大100；page从1开始 |
| include | 默认dashboard,options；options表示仅返回选项，不必重算图表 |
| option_q,option_page,option_page_size | 批次选项搜索及分页，默认1/50，最大100 |

完整请求示例：

```text
GET /api/v1/compliance/agent-traces/statistics?batch_id=batch_001&language=zh&list_filter=all&page=1&page_size=6
```

完整可运行字段结构见 [S01.json](./agent-trace-statistics-examples/S01.json)。替换其中 mock ID 和数据即可作为联调响应，禁止把它当作生产统计。

| 字段 | 内容 |
| --- | --- |
| resolution | resolved/defaulted/empty |
| resolved_selection | batch_id,snapshot_id,projection_version,language；空范围null |
| scope | 上述身份及sample_count；可附schema_version,policy_version,created_at |
| batch_options | PageResult；item带批次标识、display_id、name、active_snapshot_id、batch_version、sample_count、languages[{code,count}] |
| language_options | [{code,label,count}]；数量属于未过滤整批 |
| kpis | 下表8个Metric |
| charts | 5.4式结构，详见下节及样例 |
| completeness | 三项覆盖率、required_fields、missing_union_count、overlap_summary |
| list_counts | {all,risk,missing_fields} |
| list_context | 当前L身份、排序、页面大小、fingerprint |
| sample_page | S02形状，首次无需重复调用列表 |
| permissions | can_view_statistics,can_list_samples,can_view_detail,can_copy_json,can_view_raw,can_export |
| export_options | kinds,contents,required_contents,redaction_profiles,default_scope,max_selected_trace_ids |
| module_availability | ingest/statistics/execution/tools可用性，前端已有对应工作区 |
| warnings | [{code,message,panel}]，解释真实限制 |

无已发布快照：scope/resolved_selection为null；返回选项和空sample_page，页面提示先解析。有聚合权限但无列表权限时，permissions明确false，sample_page为空且保留合法分页/context；不能泄露摘要。

### Metric 与计算

每个 Metric 包含 `value,unit,availability,valid_sample_count,eligible_sample_count`，可选 `numerator,denominator,reason_code,reason`。availability=available/partial/unavailable/not_applicable；后两者不显示数值0。

| kpis字段 | unit | 计算规则 |
| --- | --- | --- |
| sample_count | count | B内有效解析样本去重数 |
| risk_sample_count | count | B内审计检出风险的样本去重数 |
| recorded_tokens | token | 互斥可信分量的已记录量；未知部分不补零，不是完整账单 |
| reasoning_output_ratio | ratio | C内推理合计/C内最终输出合计；C为两者均可信且语义兼容的同集合 |
| tool_call_count | count | 调用尝试去重数，重试是新attempt |
| tool_type_count | count | 标准化工具名去重数 |
| average_steps | step | 规范事件总量/事件数有效的样本数；不是消息条数 |
| task_success_rate | percent | completed样本数/B样本数×100；不含blocked、terminated |

比值分母0返回null和原因。样本未知状态不能默认completed。输入/推理/最终输出不允许重复记账；如果源output包含推理，只有语义明确且非负时才能做减法。

### charts

所有图表对象有 availability、可选 reason/reason_code。计数原值权威，比例允许独立四舍五入。

| 字段 | 必需结构 |
| --- | --- |
| test_category_distribution | denominator,items[{code,label,count,ratio_percent}]，单标签类别含unknown |
| token_composition | mutually_exclusive,normalized_policy,compatible_sample_count,incompatible_sample_count,total_recorded,components[{code,label,count,ratio_percent,valid_sample_count,eligible_sample_count}] |
| tool_ranking | total_call_count,tool_type_count,ranking_order,items[{tool_code,label,count,is_other,merged_tool_count?}] |
| duration_distribution | valid_count,missing_count,invalid_count,total_count,unit=ms,quantile_method=nearest_rank,p50_ms,p95_ms,buckets[{code,label,lower_ms,upper_ms,lower_inclusive,upper_inclusive,count}] |
| tool_result_distribution | total_call_count,terminal_count,non_terminal_count,unknown_count,items[{code,label,count,ratio_percent}]；分母为终态数 |
| behavior_matrix | row_dimension=test_category,unit=event_occurrence,overlap_allowed=true,columns[{code,label}],rows[{category_code,label,cells[{behavior_code,count}]}] |
| source_distribution | denominator,items[{code,label,count,ratio_percent}]，来源是platform/scenario/external_import/unknown |
| language_distribution | denominator,items[{code,label,count,ratio_percent}]，随当前B语言条件变化 |

时长：第一桶[0,1000]，其后(1000,2000]、(2000,4000]、(4000,6000]、(6000,8000]、(8000,10000]、(10000,+∞)，无穷upper_ms=null。负数/不可解析是invalid，不进入分位数。P50/P95对有效原始毫秒排序，取ceil(p×N)的1起始序号；空集null。

行为矩阵列：unauthorized越权、argument_error参数错误、timeout超时、duplicate重复、retry重试。按 `(snapshot_id,projection_version,trace_id,event_id,behavior_code)` 去重；同事件可命中多个行为，不把矩阵合计当调用或样本总数。未采集时unavailable，不能全填0。

调用去重必须带样本范围：不同样本都叫CALL-01不能合并。优先全局attempt_id，否则 `(snapshot_id,trace_id,call_id,attempt_index)`；重试parent_call_id在同样本内解析。pending/running/unknown调用单列，不混入成功终态。

### 完整性

source/time/reasoning各含：`available_count,missing_count,invalid_count,not_applicable_count,applicable_count,total_count,rate_percent,availability,reason?`。

applicable=total−not_applicable；available+missing+invalid=applicable。reasoning指可信推理Token数值存在（真实0有效），不是隐藏思维文本，也不是接入页usage的同义字段。

`required_fields=[source,time,reasoning]`；missing_union_count必须等于list_counts.missing_fields。overlap_summary提供time_missing_count、reasoning_missing_count、source_missing_count、time_and_reasoning_count，前端只展示不自行推断并集。

## 5. S02：列表投影

必传 `view=statistics,snapshot_id,projection_version`；默认 `language=all,list_filter=all,page=1,page_size=6`。不带接入页的隐藏source_id或issue_type筛选。旧接入默认20条的行为保持不变。

```json
{"items":[],"total":0,"page":1,"page_size":6,"total_pages":0,"context":{"batch_id":"batch_001","snapshot_id":"snapshot_001","projection_version":"stats_1","language":"all","list_filter":"all","page_size":6,"sort":"ingest_order_asc_trace_id_asc","filter_fingerprint":"scope_hash"}}
```

item完整示例见 [S02.json](./agent-trace-statistics-examples/S02.json)。必需：

- 身份：trace_id,display_id,batch_id,snapshot_id,projection_version,source_id,filename,source_format,ingest_order。
- 展示：language,test_category,test_category_label。
- token_usage：input,reasoning_recorded,final_output,total_recorded（均可null），normalization_policy,availability。
- 运行：event_count,call_count,retry_count,duration_ms（可null），task_status。
- 审计与完整性：audit_decision,missing_fields,availability（source/time/reasoning）。
- 行权限：allowed_actions={view_detail,copy_json,export_json}。

不在列表塞messages、原文或映射。最后一页允许不足6条；超出末页返回空items和真实total，不复用上一页。

执行状态：completed→成功完成、blocked→风险拦截、terminated→安全终止、running/pending→处理中、failed→执行失败、unknown→未知。audit_decision独立为risk_found/no_risk_found/pending/error/unknown。列表只显示一个“调用结果”列。

## 6. S03：一次返回复合详情

必传 `view=statistics,snapshot_id,projection_version`；携带language,list_filter,page_size以计算同一L中的邻居。

完整样例见 [S03.json](./agent-trace-statistics-examples/S03.json)。顶层包括：

| 字段 | 要求 |
| --- | --- |
| batch_id,snapshot_id,projection_version,language,trace_id,display_id | 顶层language回显查询范围（all等）；实际样本语言在summary.language，不能用实际zh覆盖范围all |
| summary | 与S02同口径的完整摘要，含内部ID和执行指标 |
| audit | decision,risk_types,evidence_refs,policy_version,availability |
| sample_json | 下面的文本及完整性元信息 |
| raw_preview | raw_text,kind(record/fragment/file),line_start,line_end,total_lines,truncated,availability,reason?,next_cursor? |
| source_ref | source_id,record_index,source_path；可扩展行号/记录路径 |
| mapping | format_code,format_label,mapping_version,rows[{source_path,target_path,description,state}]；可附truncated,total_rows |
| navigation | previous,next,position,total,page,page_size,context |
| permissions | view_detail,view_raw,copy_json,export_json,redaction_profile |
| content_chunk | 初始null；继续加载时为下述块结构 |

sample_json必需：availability,json_text,is_valid_json,complete,truncated,loaded_bytes,total_bytes,content_version,content_sha256,next_cursor,preview_scope；可附reason。preview_scope含is_complete,messages_shown,messages_total,events_shown,events_total,reason?。未知total为null。

初始样本预览≤256KiB、原始片段≤64KiB。两种情况区分：

1. 可解析但只含部分事件的预览对象：is_valid_json=true、complete=false、truncated=false，明确范围。
2. 不可解析的文本前缀：is_valid_json=false、complete=false、truncated=true，允许内容游标；不能称完整结构。

`content_sha256` 对应实际传给用户的UTF-8文本；content_version绑定授权副本及脱敏策略。原文无权限可单独unavailable，不必让整个允许访问的详情403。

### 邻居与跨页

```json
{"previous":null,"next":{"trace_id":"trc_0007","display_id":"AUD-0007","page":2},"position":6,"total":200,"page":1,"page_size":6,"context":{"batch_id":"batch_001","snapshot_id":"snapshot_001","projection_version":"stats_1","language":"all","list_filter":"all","sort":"ingest_order_asc_trace_id_asc","page_size":6,"filter_fingerprint":"scope_hash"}}
```

邻居按L和稳定排序查找，跨页返回真实ID和page，边界null。前端最多补一次目标列表页；不预取200次详情。样本不属于L返回409，不允许邻居越出筛选/授权范围。

### 长内容继续加载

复用S03：追加 `representation=sample|raw,content_cursor=opaque`。游标绑定操作者、样本、批次、快照、投影、表示类型与内容版本。过期410，不能接受任意文件偏移。

本版前端继续加载期待同一详情身份字段及 `content_chunk`：

```json
{"text":"后续文本","offset_bytes":262144,"next_cursor":null,"content_version":"同一授权内容版本","complete":true}
```

offset_bytes为此前累计文本的UTF-8字节数；块边界必须是完整Unicode字符。raw和sample属于同一复合详情授权版本，均与sample_json.content_version一致。前端拒绝偏移或版本不匹配，累计到1MiB停止预览并提示导出。complete=true后才校验拼接文本可解析。服务端完整导出不受预览大小限制。

mapping默认最多200行。超出应标记truncated和total_rows；本版列表展示已返回映射并提示截断，不会虚构完整映射。需要分页时可后续在同一资源增加明确分页约定。

## 7. S04—S06：任务、产物与下载

### 任务提交

```json
{
  "capability_code":"agent_trace_export",
  "name":"智能体轨迹统计 package",
  "input":{
    "batch_id":"batch_001","snapshot_id":"snapshot_001","projection_version":"stats_1","language":"all",
    "view":"statistics","export_kind":"package","format":"zip",
    "scope":{"type":"filtered","language":"all","list_filter":"all","trace_ids":[]},
    "contents":["stats_summary","sample_table","normalized_json","manifest"],
    "redaction_profile":"standard","anonymize_ids":true,
    "locale":"zh-CN","timezone":"Asia/Shanghai","ui_version":"statistics_v1"
  }
}
```

前端input保留聚合scope的版本上下文，可能附schema_version/policy_version/created_at/sample_count；这些只能用于回显核对，服务端必须重新依据已授权快照查询，不能信客户端统计数。真正导出范围取input.scope，不从当前可见六行推断。

| 类型 | export_kind/format | scope / contents |
| --- | --- | --- |
| 当前视图 | view/png | filtered当前语言；contents=[statistics_png]；附ui_state={list_filter,page,page_size}；KPI仍属主B |
| 结果包 | package/zip | 默认filtered+all；可显式当前列表子集；manifest记录主范围和明细范围差别 |
| 单样本 | sample_json/json | scope.type=sample、trace_ids恰好一条；完整授权内容，不导出截断预览 |

S01.export_options：kinds[{export_kind,formats,availability,reason?}]；contents[{code,label,availability,reason?}]；required_contents（例如manifest）、redaction_profiles、default_scope、max_selected_trace_ids。原始文件默认不选且单独授权。未支持格式/内容提交时422，不能用改扩展名的JSON冒充PNG/ZIP。

X-Request-Id用于幂等：同操作者、方法、路径、同载荷同任务；同键不同载荷409，保留至少24小时。前端网络重试保留键。每次重试仍验证权限。导出任务状态与样本completed不共用枚举。

### Task 响应

```json
{"task_id":"task_001","status":"succeeded","progress":100,"result":{"kind":"agent_trace_export","batch_id":"batch_001","snapshot_id":"snapshot_001","artifacts":[{"artifact_id":"artifact_001","filename":"statistics.zip","mime_type":"application/zip","batch_id":"batch_001","snapshot_id":"snapshot_001"}]}}
```

pending/running/succeeded/failed/cancelled。progress未知可省略或null；失败返回error_message。S05可返回retry_after_ms，前端串行轮询2—10秒，避免并行堆积。产物可扩展size_bytes,sha256,expires_at，生产应返回真实值。只有文件已经生成且可下载才能succeeded。

### 票据

S06 body={}，X-Request-Id为新键。JSON data：

```json
{"download_url":"/api/v1/files/download?t=opaque","filename":"statistics.zip","expires_at":"2026-11-07T12:05:00+08:00","mime_type":"application/zip","size_bytes":125600,"authorization_mode":"ticket"}
```

本版前端只接受同源下载地址，二进制使用fetch credentials=same-origin，不附加Bearer，票据必须在URL中完成授权。文件响应不包JSON envelope；设置正确Content-Type和UTF-8 Content-Disposition。票据过期可重新申请，不重建导出任务。需要外部对象存储时，请提供同源代理，不能要求前端把平台token发给任意外域。

### ZIP manifest

至少包含schema_version,batch_id,snapshot_id,projection_version,policy_version,created_at,aggregate_scope,sample_scope,filter_fingerprint,sample_count,contents,redaction_profile,anonymize_ids,files[{path,mime_type,size_bytes,sha256}]。

样本范围默认主B全部，列表筛选不会意外缩成6条；选子集时清楚记录汇总与明细不同分母。匿名化在同一产物所有文件/路径中一致；生产脱敏由授权策略执行。规范内部路径防ZipSlip；若导出CSV须处理公式注入。本版Mock明细文件为JSON。

## 8. 错误与权限

| 状态 | 预期 |
| --- | --- |
| 401 | 平台统一清理登录并跳转 |
| 403 | 无权限，不能返回其他用户样例 |
| 404 | 对象不存在或安全隐藏；未部署接口应给可区分原因 |
| 409 | 上下文不匹配或幂等冲突 |
| 410 | 快照/投影/内容游标/产物/票据过期 |
| 413 | 体积限制，提示改用授权导出 |
| 422 | 参数、格式、能力选项不支持 |
| 429/503 | 限流或暂不可用，返回可读原因与重试建议 |
| 200部分不可用 | 字段availability和reason，其他面板照常展示 |

服务端每次校验统计/列表/详情/原文/复制/导出权限，不能只信S01权限位。详情、原文与导出使用同一脱敏策略。日志不记录完整源文本、Bearer或票据；保留操作者、对象、快照、脱敏版本与导出范围审计。

## 9. 联调命令与验收顺序

```powershell
curl.exe -H "Authorization: Bearer <平台令牌>" "http://localhost:<后端端口>/api/v1/compliance/agent-traces/statistics?language=all"
curl.exe -H "Authorization: Bearer <平台令牌>" "http://localhost:<后端端口>/api/v1/compliance/agent-traces/batches/<batch_id>/samples?view=statistics&snapshot_id=<snapshot_id>&projection_version=<projection_version>&language=all&list_filter=risk&page=2&page_size=6"
```

1. 确认共享env/proxy仍指向目标后端；切父容器到“真实接口”。没有新token头或新登录方案。
2. 首屏只有一次S01，不应附带接入workspace或逐条详情请求。
3. S01所有互斥分项总和及缺失并集正确；测试未知语言、空集、输出0、负耗时、部分不可用。
4. 翻页/风险/缺失只调S02，KPI保持主范围。没有数据越租户或越快照。
5. 打开详情一次S03，切页签0请求；跨第6/7条及首尾正确；三页签身份一致。
6. `json_text`中的原始键与转义字符串保真；测试长文本字节偏移与过期游标。
7. 三种导出文件真实有效；包内条数、manifest、hash、匿名化一致；幂等重试不创建重复任务。
8. 失败不切Mock；401由平台处理；权限不足、快照过期、取消和模式切换无旧数据闪回。
9. 旧接入接口未传view时、既有合规子页、平台任务和下载服务均保持兼容。

协议样例来自当前已有接入演示快照，数值与设计截图不同：200样本、1,400调用、18平均步骤、1工具种类、382,400已记录Token、44条缺失并集。生产不要固化这些数字。完整原因见[前端使用说明](./智能体轨迹审计-统计指标-前端实现与使用.md)。

## 2026-11-08 当前实现接口核对与自动下载补充

本节按当前页面、API 适配器、store/composable 和 TypeScript DTO 核对，区分现有调用与规划扩展；与前文历史交互描述冲突时以本节为准。接口齐备指前端调用及交接契约覆盖，不代表真实后端已经部署或完成联调。

### 当前视图导出闭环

1. `POST /tasks/execute`，`capability_code=agent_trace_export`。快速返回 JSON envelope 内的 Task，不直接返回文件。随后通过 `GET /tasks/{task_id}` 查询；立即成功和异步成功必须使用同一结果结构。
2. `pending/running` 返回 `progress`（0—100，未知可 null）；`failed/cancelled` 返回可展示的 `error_message`。仅文件已经生成并可读取时返回 `succeeded`、`progress=100`。同一任务的终态与产物 ID 保持稳定。
3. 成功结果必须含 `result.kind=agent_trace_export`、`batch_id`、`snapshot_id`、非空 `artifacts`。当前视图应返回一个 PNG 产物，字段至少为 `artifact_id/filename/mime_type/batch_id/snapshot_id`；生产还应返回实际 `size_bytes/sha256/expires_at`。PNG 的 MIME 为 `image/png`，文件内容必须是真实 PNG。
4. **最终代码流程已变更**：Task 成功且 artifacts 非空后，由 ViewExportStatus 调用 tracePagePng，对浏览器当前 .agent-traces DOM 生成 PNG，再以本地 Blob URL 自动下载。此入口目前不调用 download prop、不领取 download-tickets，也不读取后端 PNG 字节；artifacts[0].filename 仅参与文件命名。真实模式仍先提交/查询真实任务；Mock 模式使用演示任务。因此后端任务和渲染能力仍是入口前置依赖，不能因本地截图就省略任务接口或伪造成功产物。
5. ZIP 结果包及其他原有文件下载继续使用票据协议：POST download-tickets、body={}，返回 download_url/filename/expires_at，再 GET 同源字节流。文件 GET 使用 fetch(credentials=same-origin)，不添加 Bearer；需票据 URL 或会话授权，失败返回非 2xx。文件内容不是 JSON envelope，下载地址不能是磁盘路径或登录 HTML。
6. 当前状态栏将后端任务进度映射到 0—70%，本地 DOM 复制/图片编码为后续阶段，触发下载后到 100%；这不是后端 progress 原值，也不表示浏览器磁盘落盘已验证。后端仍只返回自己的真实 progress，不需改为页面组合百分比。

验收应分别验证真实任务、浏览器 PNG 和后端产物：任务失败/空 artifacts 不生成页面图；重复终态不重复下载；本地图片含 Canvas/SVG 和当前展示内容；ZIP 的票据 403/410 与字节流失败独立验证。截图完整性不等于后端 PNG 模板一致性，HTTP 联调必须关闭示例模式。

### 统计页实际调用与范围补齐

S01—S06 覆盖首屏、筛选分页、JSON 抽屉/继续加载/邻居定位、导出和下载；`GET /statistics` 不应替换为 workspace。样本列表和详情必须接受 `view=statistics`，继续加载复用详情接口的 `representation/content_cursor`，不得另要求前端调用一个未接入的分块地址。

当前视图 `scope.type=filtered`、`scope.language` 为已查询语言、`scope.list_filter=all`、`scope.trace_ids=[]`；实际屏幕列表筛选及页码在 `ui_state={list_filter,page,page_size}`。后端渲染 KPI/图表时按主查询范围，渲染列表时再应用 ui_state 的筛选和分页；不能因列表切到 risk 而把所有统计改成风险子集。当前 input.ui_version 为 statistics_v1。

结果包选择“当前列表子集”才将 scope.list_filter 改为当前列表筛选，否则为 all，数据条数不受当前分页限制。sample_json 使用 scope.type=sample 和一个 trace_id；没有 ui_state。manifest 必选规则只用于 ZIP，不能据此拒绝仅有 statistics_png 的 PNG 请求或 normalized_json 的 JSON 请求。input 中额外回显的 schema_version/policy_version/created_at/sample_count 不作为客户端可指定的统计事实。

首屏必须提供 permissions、export_options、module_availability、warnings、sample_page.context/list_context；抽屉必须提供 sample_json.preview_scope 和 content_chunk（初始 null），避免页面无从判定全文、截断与可复制状态。字段具体结构以本文前述 DTO 表为准，不用省略字段代替合法空数组或明确 null。

## 最终页面逐操作与响应校验清单（2026-11-08 复核）

| 页面动作 | 实际请求/必须返回 |
| --- | --- |
| 首屏及点击查询 | GET statistics；查询提交 batch_id/language/list_filter=all/page=1。返回 scope/resolved_selection、首屏全部模块及 sample_page.context |
| 搜索/续取批次选项 | GET statistics，include=options、batch_id、option_q、option_page；读取 batch_options，保留当前选中项 |
| 切全部/风险/缺失字段列表，翻页 | GET batches/{batch_id}/samples?view=statistics，携带当前 Query 并修改 list_filter/page；返回 context 和真实分页 |
| 打开样本 JSON 抽屉 | GET samples/{trace_id}?view=statistics，沿用查询范围；返回 summary、sample_json、raw_preview、mapping、source_ref、navigation、permissions、content_chunk |
| 抽屉上一条/下一条 | 读取 navigation 的目标 trace_id 再请求详情；若目标 navigation.page 不同，自动请求对应列表页，保留抽屉 |
| 继续加载样本/原文 | 同一详情接口，representation=sample/raw、content_cursor；返回身份字段及 content_chunk |
| 复制 JSON | 前端本地处理已加载且允许复制的内容，不需要新增 copy 接口 |
| 导出当前视图/结果包/完整样本 JSON | 共用 tasks/execute，export_kind 分别为 view/package/sample_json；后两者不受本次 PNG 自动下载交互变更影响 |

**拒绝展示的条件：**首屏 scope 必须匹配请求范围，sample_page.context 必须匹配主 scope 和列表条件，sample_page.page 必须与请求一致；列表的 context/page 也须匹配；详情 trace_id、summary.trace_id、navigation.context 必须属于同一查询范围。不能省略 context，不能返回最新快照来替代请求的旧快照。navigation.page 为目标所在的真实列表页，不是固定 1。

**内容分块实际约束：**content_chunk 必须含 text、offset_bytes、next_cursor、content_version、complete。offset_bytes 等于浏览器当前累计文本 UTF-8 编码后的字节数，不是字符数或 UTF-16 单位。chunk.text 为接续文本，不要重复返回已加载前缀。sample/raw 两种 representation 的 chunk.content_version 当前都与 sample_json.content_version 比较，因此需共享同一详情内容版本标识；若后端采用独立原文版本，需要先协调修改前端，不能直接返回另一个版本。样本 JSON complete=true 时前端会 JSON.parse 完整拼接文本；next_cursor=null 与 complete 应一致。客户端预览最多 1 MiB，超限需走授权完整导出，不新增超大同步预览接口。

当前返回空列表也需要 context、page/page_size/total/total_pages。KPI、图表不可用时保留结构并返回 availability/reason 与允许的 null，而不是省略整个模块。批次选项文案会直接读取 sample_count 和 languages[]，请勿仅返回 batch_id/display_id。

当前 matchesList 还严格检查 context.page_size === 请求 page_size（未传时为 6）；因此首屏默认页大小必须为 6，显式请求的合法页大小应按请求回显。不要对有效 page_size 静默裁剪后仍返回成功，否则页面会报“范围不一致”。scope.language 未传时默认 all，响应须明确为 all，不要省略或返回 null。
