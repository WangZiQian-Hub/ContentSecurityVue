生成后端响应样例（只写项目docs）：

```powershell
$env:GENERATE_STATISTICS_EXAMPLES='1'
npm run test -- src/mock/agent-trace-statistics.test.ts
Remove-Item Env:GENERATE_STATISTICS_EXAMPLES
```

浏览器脚本使用已有Playwright运行库和安装的Microsoft Edge，不在项目新增依赖。设置PLAYWRIGHT_MODULE为本机Playwright模块目录或让Node可解析playwright后运行：

```powershell
$env:PLAYWRIGHT_MODULE='<本机Playwright模块目录>'
node scripts/agent-trace-statistics-browser-check.cjs
```

脚本自行启动本地1226端口Vite（仅测试进程使用Mock环境），保存证据到本目录下的验证子目录，并在结束时停止自己的服务。若运行环境限制启动浏览器，需要该环境批准本地浏览器进程；不需要变更项目权限或平台鉴权。
