# 智能体轨迹审计：统计指标页实现与使用

更新日期：2026-11-07。

## 1. 入口与运行

页面路由：`/compliance/agent-traces?view=statistics`。

在项目目录运行：

```powershell
npm run dev
```

打开开发服务器显示的地址，进入“全链路合规治理 → 智能体轨迹审计 → 统计指标”。原有“轨迹接入与校验、思维路径、工具交互”入口保留。

合规父容器右上角的“示例演示 / 真实接口”是唯一模式开关。示例演示读取接入工作区的内存批次与快照；真实接口使用共享 Axios 请求器。服务不可用、没有权限或登录失效时，不会切换为演示数据。生产登录行为仍由平台原有路由守卫负责。

本次只修改 `ContentSecurityVue` 目录。没有修改外部 `doc` 中的三份任务说明，也没有修改后端或模型项目、共享请求器、平台鉴权与应用壳。

## 3. 主查询与列表范围

主范围：`batchId + snapshotId + projectionVersion + language`。

上方 KPI、所有图表和完整性均属于主范围。列表另加 `listFilter=all|risk|missing_fields`。切换列表页签或翻页仅调用列表接口，不改上方统计。导出结果包默认是当前主范围全部样本，不是当前六行。

提交查询清空旧结果、关闭旧详情并取消过期请求。查询成功后一次性替换整组统计和初始列表。响应中的批次、快照、投影、语言、列表筛选与页码必须匹配当前请求，否则拒绝展示。

URL仅保留页面标识 `view=statistics`。批次、快照、语言、列表筛选、页码与当前样本均保存在页面状态，不随操作写入网址。兼容已有长链接：首次读取其范围后清理为简短地址；刷新简短地址重新加载默认范围。切换运行模式后清除原模式对象ID。

## 4. JSON 抽屉

打开时立即显示加载态并清除上一条文本；一次 S03 返回三个页签。普通页签切换没有新请求。代码通过 Vue 文本节点着色，不使用源日志 `v-html`。

详情头部显示样本展示编号，业务请求始终使用内部 `traceId`。语言、类别、步骤、调用、时长与 Token 来自同一个详情的 `summary`。执行状态与风险判定分开：`completed` 不等于“未检出风险”，绿色 `terminated` 也不表示通过审计。

`sampleJson.jsonText` 与 `rawPreview.rawText` 使用服务端返回的字符串，不从被 camelCase 转换后的 DTO 重新拼原文。源键 `tool_call_id`、`User_ID` 等保持原样。

完整且可解析、允许复制的 JSON 才能标为“复制 JSON”；可解析预览明确标为“复制预览 JSON”；文本前缀不能冒充完整 JSON。一次样本预览最大 256 KiB、原始片段最大 64 KiB；继续加载使用同一个 S03 和内容游标。前端检查内容版本、字节偏移，累计预览最多 1 MiB。更大的样本使用任务导出全量授权内容。

抽屉关闭、遮罩、Esc 使用 Element Plus 行为；额外恢复触发按钮焦点。上一条/下一条在当前列表子集中导航，首尾禁用，不循环。跨页成功后更新列表页，关闭不重新请求聚合。

## 6. 演示数据与截图的差异

现有接入批次 `mock_batch_demo / mock_snapshot_1` 有 200 条轨迹，每条 18 个事件、7 次 `web.search` 调用。为了让接入页与统计页描述同一批次，没有将它们伪装成截图的 14.2 步、486 次、8 种工具。

当前默认演示聚合基线：

| 项目 | 实际值 |
| --- | --- |
| 样本、风险样本、成功率 | 200、128、172/200 = 86% |
| 事件/调用/工具种类 | 3,600 / 1,400 / 1 |
| Token | 输入192,000、推理64,000、最终输出126,400；已记录总量382,400 |
| 同口径推理/输出 | 160条；64,000/126,400 ≈ 0.51 |
| 时间 | 192条有8,600ms，8条缺失；P50/P95均8.6s |
| 推理字段 | 160条可用；40条缺失 |
| 缺失并集 | 44条，因为时间与推理缺失交集为4条；不是8+40，也不是强写40 |
| 类别 | 40、36、32、28、34、30 |
| 工具终态 | 1,162成功、168失败、70拦截 |
| 来源/语言 | 80/70/50；中文100 / English100 |

风险、执行状态、来源、行为事件及工具终态是明确写入演示源记录的元数据，聚合器从记录读取。用户导入的新文件没有这些字段时显示未知或未提供，不沿用默认批次的审计结果。真实 HTTP 模式完全由后端数据决定。

单样本标准化 JSON 包含完整事件和授权源记录，源记录与事件汇总是不同表示；不能把消息条数当事件数。原始片段标注记录范围，不称为整个 JSONL 文件。

## 7. 导出与运行限制

导出统一经过 S04 创建任务、S05 取状态、S06 领取票据。平台状态仍为 pending/running/succeeded/failed/cancelled。真实模式约2秒开始串行轮询，最多10秒间隔；停止本地查询不取消后台任务，当前页可恢复。离开统计页后停止轮询；后台任务不被前端删除。

Mock 导出也遵循任务流程，PNG 是固定图表和列表模板，JSON 可解析，ZIP 可解压并包含 manifest、所选明细及标准化 JSON。PNG 为数据报告模板，布局与浏览器页面接近，并非截取整个平台外壳。样本编号默认匿名化，敏感文本的正式授权与脱敏仍必须由真实后端实现，演示数据不提供生产脱敏算法。

下载票据使用公共 JSON 请求器；二进制下载使用现有受信同源下载函数，不向外部地址发送平台 Bearer。当前工程只接受同源文件下载（Mock 接受本地 blob）。对象存储可由后端提供同源票据代理。

真实后端未部署目标统计资源时，页面明确提示接口尚未部署/服务不可用，不展示假成功。已有“执行路径/工具交互”的能力维持原实现，本次不新增审计模型算法。
