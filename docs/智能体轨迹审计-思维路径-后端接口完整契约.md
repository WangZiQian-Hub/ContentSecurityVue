# 智能体轨迹审计思维路径 后端接口与数据细则

日期：2026年11月7日。配套：[前端实现与使用](./智能体轨迹审计-思维路径-前端实现与使用.md)、[后端接入使用文档](./智能体轨迹审计-思维路径-后端接入使用文档.md)。前序03定义接入、06定义统计；本文件只增加 execution 展示投影，不替换前序默认契约。

## 1 现状与接口边界

已核实前端 `src/api/agent-traces.ts` 存在 workspace、samples、detail、execute、task、ticket，以及创建批次、上传和绑定方法。本文定义这些资源在 `view=execution` 下的目标扩展；尚未核实后端实现，不宣称接口现在可调用。前端代码任务只允许改ContentSecurityVue，后端人员依据本文另行实施，不要求前端越界修改后端目录。

| 编号 | 方法及路径（省略 /api/v1） | 资源与扩展 |
| --- | --- | --- |
| E01 | GET `/compliance/agent-traces/workspace` | 新增execution工作区投影：批次选项、批次摘要、初始样本页 |
| E02 | GET `/compliance/agent-traces/batches/{batch_id}/samples` | 新增execution筛选与样本审计摘要 |
| E03 | GET `/compliance/agent-traces/batches/{batch_id}/samples/{trace_id}` | 新增execution复合详情及有界分段 |
| E04 | POST `/tasks/execute` | 复用平台任务，能力agent_trace_export，增加execution导出参数 |
| E05 | GET `/tasks/{task_id}` | 复用平台任务状态和产物 |
| E06 | POST `/compliance/agent-traces/artifacts/{artifact_id}/download-tickets` | 沿用接入/统计导出下载票据 |

共6个HTTP操作，不新增领域URL。`section`仅控制同一样本资源返回的有界投影，不为每个节点创建路由。列表一次批量查询当前页摘要；E03按样本聚合读取，不要求内部再发数十次HTTP。不得占用 `/compliance/traces/{id}`，那是平台另一类溯源资源。

旧调用不传view时维持旧接入DTO和默认行为；view=statistics继续沿用06；view=execution显式分发本文DTO，不要求旧客户端接受结构被替换的响应。createBatch/upload/bind等旧入口全部保留。本文使用前端已有资源并提出后端扩展，不意味着旧后端无需适配。

## 2 平台公共契约

HTTP字段snake_case，前端request递归转camelCase且解包data。统一响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "trace_id": "http_trace_01",
  "timestamp": "2026-11-07T09:00:00+08:00"
}
```

code=0成功；错误码按平台统一注册，不由本页自造。错误返回合适HTTP状态及同类envelope，不用200掩盖鉴权失败，不返回共享request无法解包的204。`envelope.trace_id`是HTTP追踪号，`data.trace_id`是业务样本号。

鉴权使用Authorization Bearer；沿用X-Request-Id和X-Trace-Id。租户、用户、批次、快照、样本、事件、产物关联必须服务端校验，不因ID可猜或前端隐藏即认为安全。所有POST以“操作者+方法+路径+X-Request-Id”幂等：同键同规范化载荷返回同一结果，同键不同载荷409；至少保留24小时；幂等命中仍校验权限。同一次网络重试沿用键，新业务动作换键。

任意源JSON/工具参数/工具返回必须序列化为 `raw_text`、`input_json`、`output_json` 字符串，不被递归改键破坏。路径也是字符串。动态维度使用`[{code,label,count}]`，不以未知来源字段或AUD编号作对象键。

分页统一 `{items,total,page,page_size,total_pages}`，page从1开始。空集合total=0,total_pages=0,page=1；超末页返回空items和真实total，由前端恢复有效页。非法参数422。所有计数非负整数，超JS安全整数不得静默截断。时间ISO8601带时区；duration_ms/relative_time_ms为毫秒；缺失null，真实0有效。

availability统一 available/partial/unavailable/not_applicable，附稳定reason_code和中文reason。权限/缺失/尚未审计不是同一种状态。页面不暴露未授权字段；无原文权限不影响已授权的脱敏面板整体读取。

## 3 范围、版本与领域模型

固定结果范围 `B = authorized tenant + batch_id + snapshot_id + projection_version`；样本列表 `L = B + q + language + risk_level + audit_decision`；详情 `D = B + trace_id`。当前页面主查询只有batch，语言等是左侧局部筛选，不改变批次总量。

snapshot_id为已发布不可变解析快照；projection_version为该快照的审计投影版本，包含规则版本。更新风险判断或摘要需发布新projection_version，不在同一版本内偷偷替换。E01 dashboard解析当前版本后返回固定scope；E02/E03/E04必须沿用。版本已回收返回410，请用户重新查询，不能静默返回新版本。权限、脱敏策略版本另参与缓存键。

| 对象 | 必须保持的关系 |
| --- | --- |
| batch | 内部batch_id与展示display_id分开，active_snapshot_id可null |
| sample | trace_id属于batch+snapshot；display_id只展示，ingest_order决定列表顺序 |
| event | event_id在样本中稳定唯一；ordinal为源顺序，允许有缺口且不补造记录 |
| tool attempt | call_id为规范调用尝试唯一标识；源重复ID另存source_call_id；重试有独立attempt_id和parent_call_id |
| evidence | evidence_id、event_id、rule_id、rule_version、policy_version明确，支持一事件多证据 |
| pattern | pattern_id+event_id+evidence_id组合可定位，不凭中文标签反查 |
| content | content_version、redaction_profile、permissions_version决定可见文本及偏移坐标 |

审计结论沿用统计契约：risk_found/no_risk_found/pending/error/unknown；risk_level=high/medium/low/none/unknown。pending/error/unknown不得自动写low或none。导入test_category与检测risk_types分开。平台Task状态pending/running/succeeded/failed/cancelled；样本执行状态和工具调用结果另用前序枚举，不混淆。

## 4 E01 工作区

### 4.1 参数

| 参数 | 规则 |
| --- | --- |
| view | 本页必传execution；不传维持接入旧行为 |
| include | options/dashboard；本页默认options；dashboard已包含当前可见批次选项、摘要和初始样本页 |
| batch_id | options可选，用于定位选项；dashboard必填，缺少422，不暗自换批次 |
| snapshot_id、projection_version | dashboard可选，未给解析当前已发布版本；指定则验证归属和存在性 |
| option_q | 批次搜索最长100字符，只搜索选项，不筛选样本 |
| batch_option_page、option_page_size | 1、50；上限100；沿用旧batch_option_page，不改旧option_page语义 |
| q、language、risk_level、audit_decision | dashboard初始样本过滤，默认空/all/all/all；含义同E02 |
| page、page_size | dashboard列表默认1、6，最大100 |
| trace_id | 可选定位目标，必须在L中；合法时返回所在sample_page，不在L则返回selected_trace_id=null和定位提示 |

普通点击查询清除局部筛选；URL恢复或相同scope重试可携带明确过滤。options请求本身只返回选项，不产生分析任务或改变appliedScope。当前前端在首次进入或切换模式时，收到options后会选取URL明确指定的batch_id或选项第一项，自动继续请求dashboard及默认样本overview，让首屏直接展示已有结果；之后下拉批次改变仍须点击查询才生效。此流程复用原接口及字段，dashboard仍必须携带batch_id。无可用选项且未显式指定批次时不发dashboard请求。

### 4.2 返回字段

| 字段 | 类型与内容 |
| --- | --- |
| view/include | execution及本次投影类型 |
| batch_options | PageResult，item含batch_id/display_id/name/batch_version/active_snapshot_id/availability/reason |
| resolved_selection | draft batch_id，可null；只是选项解析，不是已查询结果 |
| scope | dashboard有：batch_id/snapshot_id/projection_version/schema_version/policy_version/permissions_version；无可用快照null |
| batch_summary | sample_count、by_language[{code,label,count}]、availability/reason；整批快照计数 |
| queried_at | dashboard成功读取时间，ISO8601；options不提供，不能伪称分析时间 |
| analyzed_at | 实际审计时间，可null；和queried_at不同 |
| sample_page | E02同构分页；dashboard返回，options省略 |
| list_context | 规范化筛选、sort、filter_fingerprint、scope；与sample_page一致 |
| selected_trace_id | dashboard默认当前页第一条或有效定位，空页null |
| permissions | can_query/can_list_samples/can_view_detail/can_view_raw/can_export |
| export_options | kinds、contents、redaction_profiles、required_contents、scope_types及不可用原因，同第8节 |
| warnings | code/message/panel；解释部分缺失，不掩盖跨scope错误 |

无批次时options空且selection=null；批次存在但未发布快照时dashboard返回availability=unavailable、reason_code=no_published_snapshot、scope=null、sample_page空，并提示回接入页。已发布的空快照则scope有效、sample_count=0，属于合法空结果。给出无权批次按平台403/隐藏存在性404策略处理，不换成别人的批次。

## 5 E02 样本摘要列表

path包含batch_id；必传view=execution、snapshot_id、projection_version。q最长100字符，按display_id、风险类别label和规范化可搜索摘要匹配，不对未授权原文全文检索而泄露命中信息。language=all/zh/en/other/unknown；risk_level=all/high/medium/low/none/unknown；audit_decision=all或第3节五类；每种筛选单选，条件之间AND。搜索大小写不敏感，空白trim，禁止直接拼接SQL/正则。page默认1/page_size默认6，上限100。

排序固定 `(ingest_order ASC, trace_id ASC)`，总数为L去重样本数。PageResult额外含context（B+规范过滤+sort+filter_fingerprint）。items字段：

| 字段 | 类型与口径 |
| --- | --- |
| trace_id/display_id/source_id/ingest_order | 内部ID、展示ID、来源、稳定顺序 |
| language/test_category | 真实语言、导入测试标签；unknown可用，不冒充中文 |
| audit_decision/risk_level/risk_types | 结论、等级、`[{code,label}]`；不由test_category推算 |
| event_count/call_count/duration_ms | 有效记录事件数、去重调用尝试数、可证实耗时（毫秒） |
| field_availability | `[{field,state,reason_code,reason}]`解释缺失值 |
| allowed_actions | view_detail布尔及不可用原因 |

样本列表不带原文全文、图大对象或全部证据；禁止一行一请求。sample_count是整批总量，E02.total是筛选命中数，items.length是当前页数量，三者必须能区分。

当前实现的面板标题采用E02.total（首屏采用E01.sample_page.total），分页大小采用响应page_size；不再把items.length展示为面板总量。无筛选时total为当前授权范围内的批次样本数，有筛选时为命中总数。此调整复用现有分页字段，不新增计数URL或额外后端操作。

## 6 E03 样本复合详情

### 6.1 请求分段

必传view=execution、snapshot_id、projection_version；path中的batch_id/trace_id必须归属正确。通用参数：redaction_mode=redacted/raw（默认redacted，raw无权403）；event_id可选；event_page=1、event_page_size=50，上限100；pattern_page=1、pattern_page_size=20，上限100。

| section | 返回内容与用途 |
| --- | --- |
| overview（默认） | scope、summary、graph首段、events首段及其selection_preview、selection、risk_distribution、danger_patterns、first_risk_event_id、permissions、availability；首次/切样本 |
| events | scope、events分页、selection及first_risk_event_id；回放跨页/日志翻页，不重复传大图与样本分布 |
| selection | scope、selection，以及目标所在events页；图/模式跨页定位、原文模式切换和完整摘录按需读取 |
| graph | scope、graph下一段；使用graph_cursor续取，不重复所有面板 |

section=selection必须event_id；否则422。overview传event_id则定位该事件所在页，event_page被定位结果覆盖；不传默认首个风险事件，若没有则第一事件。events不传event_id时选当前页首项。事件不存在或不属当前样本404，不能换选另一事件冒充成功。所有分段都带scope及trace_id，客户端必须核对。

同一overview可用pattern_page切危险模式页，保留event_id；响应仍是完整overview结构但可复用缓存，默认不改变图游标。实现若日后新增patterns分段需另行版本化协商，不能悄悄返回不符合本文的局部DTO。

### 6.2 summary

复用E02样本摘要，补充batch_id/snapshot_id/projection_version、event_total、call_total、duration_source、recorded_at、analysis_availability。event_count/event_total必须同口径；18步指18条已记录标准化事件，调用量另按唯一call attempt计数，返回事件不重复计调用。duration_source=explicit/derived/not_provided：优先显式持续时间；否则仅用可靠起止时间计算，禁止将每个并行工具时长相加冒充总耗时。

### 6.3 graph

```json
{
  "nodes": [{"event_id":"ev_07","display_id":"STEP-07","ordinal":7,"event_type":"reasoning_summary","label":"推理摘要","risk_level":"high"}],
  "edges": [],
  "total_nodes":18,
  "loaded_nodes":1,
  "complete":false,
  "next_cursor":"opaque_cursor",
  "ordering":"ordinal",
  "availability":"available"
}
```

此片段仅展示单节点字段，不是完整18节点fixture。节点另可含has_evidence/source_ref/call_id。edge字段edge_id/from_event_id/to_event_id/relation/evidence_refs；relation=sequence/branch/call_return/causal等已声明编码。sequence仅说明记录顺序。缺失关联不可生造causal边。

每段最多500轻量节点，graph_cursor由服务器签发并绑定scope/trace_id/权限版本，有效期内稳定。loaded_nodes为截至当前游标累计节点数，complete只在最后一段true。边按“两个端点中较后装载的端点所在段”返回，每条一次，使前端合并后端点完整；有源记录指向快照外节点时返回unresolved_refs而不是伪造节点。跨段选择事件可先加载selection和所在图段：selection返回graph_locator.cursor（目标所在段的起始游标，首段为null）供客户端追加加载，不能为每个节点建路由。

### 6.4 events 与 selection_preview

events为PageResult，total是当前样本全量可见记录数；ordinal升序、同ordinal以event_id打破平局，前端沿此顺序回放。没有记录的序号不补。每行字段：event_id/display_id/ordinal/event_type/label/relative_time_ms/timestamp/description/call_id/risk_level/evidence_summary/source_ref/selection_preview。

selection_preview使用6.5的Selection结构，但content每个文本最多4096 UTF-16单位、lineage节点最多50、risk_evidence最多20，显式truncated及total。预览禁止截断半个代理对；高亮范围须相对当前可见文本重算。已经脱敏的预览不能含原文隐藏字段。这使一页事件的回放不逐条发HTTP。事件邻接返回previous_event_id/next_event_id，用于跨页边界。

### 6.5 Selection

| 字段 | 必需数据与语义 |
| --- | --- |
| event_id/display_id/ordinal | 当前事件身份，所有面板共享 |
| graph_locator | 目标图分段cursor；不是文件路径 |
| risk_evidence | items、total、truncated、next_cursor；item详见下文 |
| lineage | nodes/edges、total_nodes、complete、unresolved_refs、next_cursor、availability/reason |
| content | source_excerpt、reasoning_summary、source_ref、redaction_mode、content_version、permissions_version、availability |
| previous_event_id/next_event_id | 稳定事件序列邻居，边界null |

risk_evidence.items：evidence_id、event_id、risk_type{code,label}、match_pattern、severity、rule_id、rule_version、policy_version、review_status（pending/confirmed/dismissed/not_required）、confidence（0—1或null）、confidence_kind（score/probability/unknown）、related_call_ids[]、source_refs[]。缺置信度不能用0替代。置信度为score时不宣称概率。多个rule命中同事件保留多个evidence；分布仍按事件去重。

lineage.nodes：id、kind=source/message/event/call、label、event_id可null、call_id可null、source_ref可null、availability；edges：from_id/to_id/relation/evidence_refs。关系来自来源引用或审计传播记录，不能仅按排序连成因果链。

content.source_excerpt：text、source_ref、highlights[]、content_version、loaded_units、total_units、truncated、next_cursor、availability。reasoning_summary同结构，增加provenance=imported/derived_summary、生成者/规则版本（若有）；只呈现已存储文本，不在查询时让模型临时编造推理。派生摘要明确标“审计摘要”，不冒充原始模型推理。

highlights为 `{start,end,label,evidence_id}`，以返回text为基准的零基UTF-16区间 `[start,end)`，禁止越界、切开代理对。source_ref中的原始字符位置另放source_char_start/source_char_end和offset_unit，不与展示片段坐标混淆。token_range独立含start/end/tokenizer_id，缺tokenizer不得标成精确Token范围。脱敏后文本改变则返回新的highlights和content_version，不复用原文偏移。

source_ref含source_id、record_index（1起）、source_path（字符串）、line_start/line_end（1起）、message_index/block_index（0起，可null）、content_hash；不得返回服务器绝对磁盘路径。记录缺失则availability=unavailable及原因，不以空字符串假装真实空原文。

完整selection仍需有界：单次每类文本最多16384 UTF-16单位，证据最多100条、来源链最多200节点。超限使用 `selection_cursor` 继续同一个section=selection和event_id，cursor编码资源类别/起点并绑定内容版本；返回selection_segment={kind,items或text,offset,next_cursor,complete}及scope/event_id。首次无cursor返回完整Selection外壳；带cursor只返回selection_segment，前端追加到指定类别，不整体覆盖Selection。禁止把截断数据标成complete。

### 6.6 风险分布和危险模式

risk_distribution：scope=sample、count_unit=distinct_event、total_risk_events、items[{code,label,event_count}]、availability。每个行为内按event_id去重，同一事件可属于多个行为，items总和可能大于total_risk_events。低风险与无风险严格区分，分布由后端计算，前端只绘制。

danger_patterns为PageResult，另含complete（当前响应是否包含全部模式）。item：pattern_id/label/event_id/event_display_id/evidence_id/snippet/risk_level；按ordinal、pattern_id稳定排序；snippet使用当前授权脱敏模式，不泄露原文。first_risk_event_id是整个样本有有效未驳回风险证据事件中的最早ordinal，不限已加载图或日志页。无风险null；审计未完成同时返回availability=partial，前端提示“当前已记录的首个风险”。

### 6.7 overview最小结构示例

以下是合法无事件样本示意，真实有事件时各面板必须由同一源数据生成：

```json
{
  "view":"execution","section":"overview","trace_id":"trace_empty_01",
  "scope":{"batch_id":"batch_01","snapshot_id":"snap_01","projection_version":"p1","permissions_version":"perm1"},
  "summary":{"trace_id":"trace_empty_01","display_id":"AUD-EMPTY","event_count":0,"event_total":0,"call_count":0,"call_total":0,"duration_ms":null,"duration_source":"not_provided","audit_decision":"unknown","risk_level":"unknown"},
  "graph":{"nodes":[],"edges":[],"total_nodes":0,"loaded_nodes":0,"complete":true,"next_cursor":null,"availability":"available"},
  "events":{"items":[],"total":0,"page":1,"page_size":50,"total_pages":0},
  "selection":null,
  "risk_distribution":{"scope":"sample","count_unit":"distinct_event","total_risk_events":null,"items":[],"availability":"unavailable","reason":"尚未审计"},
  "danger_patterns":{"items":[],"total":0,"page":1,"page_size":20,"total_pages":0,"complete":true},
  "first_risk_event_id":null,
  "permissions":{"can_view_detail":true,"can_view_raw":false,"can_export":true},
  "availability":"partial"
}
```

示例省略了可空来源与附加摘要字段，仅说明空集合、未知结论和null selection之间的关系；完整服务实现须满足前文必需字段，不将此片段当作全部schema。

## 7 一致性和性能细则

E01汇总、E02计数、E03事件证据全部按同一B读；后台审计完成后发布新投影。缓存键包含tenant/actor权限范围、batch/snapshot/projection、trace、filters、redaction_mode/content_version，不跨用户复用未脱敏缓存。原文切换需再次鉴权，不能因快照不可变忽略权限撤回。

工作区只返回当前页摘要，事件页默认50，图段500；聚合一次读取/预计算，不内部N+1扫描所有大文本。全文来源按需分段，响应有大小限制与明确truncated。cursor不可由客户端随意修改，过期410，非法422，跨scope403或404；大数据场景仍保持确定顺序。

应记录request trace、用户、scope、section、耗时、命中缓存与导出任务ID；日志中不直接记录敏感原文或签名下载URL。监控查询失败率、投影过期、证据关联缺失及响应大小。普通读取应适配前端30秒超时，禁止用数分钟同步分析完成GET。

## 8 E04 导出任务

注册/复用能力 `agent_trace_export`，不能借用reasoning_audit等不兼容能力。命令示例：

```json
{
  "capability_code":"agent_trace_export",
  "name":"思维路径当前视图导出",
  "input":{
    "batch_id":"batch_01","snapshot_id":"snap_01","projection_version":"p1",
    "view":"execution","export_kind":"view","format":"png",
    "selected_trace_id":"trace_42","selected_event_id":"event_07",
    "scope":{"type":"sample","trace_ids":["trace_42"],"source_id":null,"issue_type":null,"q":null},
    "ui_state":{"page":1,"page_size":6,"event_page":1,"event_page_size":50,"graph_event_ids":["event_07"],"redaction_mode":"redacted"},
    "contents":["execution_png"],"redaction_profile":"standard","anonymize_ids":true,
    "locale":"zh-CN","timezone":"Asia/Shanghai","ui_version":"agent-trace-execution-v1"
  }
}
```

示例图节点集合只示意字段，真实请求传当前可见有界节点ID且必须属于当前样本；服务端验证并生成图，不能信任任意HTML。ui_state可补filter_fingerprint、list_filters、pattern_page、graph viewport；列出白名单、范围和大小限制，不能透传JS执行。PNG须包含已生效批次摘要、当前样本及选中事件，manifest/scope_summary区分批次上下文与样本内容范围。

| 入口 | 参数与导出范围 |
| --- | --- |
| 当前视图 | view/png，scope.type=sample，trace_ids恰好当前样本；contents=execution_png；ui_state保留屏幕筛选/可见页 |
| 结果包整批 | package/zip，scope.type=batch，trace_ids=[]；忽略局部列表过滤，并在确认框明确范围 |
| 结果包筛选子集 | package/zip，scope.type=filtered；scope包含q/language/risk_level/audit_decision和服务端重算fingerprint，不受page限制 |
| 结果包单样本 | package/zip，scope.type=sample，trace_ids=[当前样本] |

保留旧scope.type/source_id/issue_type/q字段含义；execution可扩展过滤字段，不影响前序统计的language/list_filter语义。显式ID列表最大100，整批不传200/数万ID，使用scope规则。任务创建时冻结规范过滤、scope和内容版本，不能下载时重新选active_snapshot。

结果包contents支持normalized_json/offline_html/evidence_index/manifest/execution_png（由export_options声明实际支持）。批量PNG不默认渲染每条样本；选择execution_png时明确仅当前样本视图，manifest记录与整批JSON范围差异。必选manifest不可取消。不支持的类型422，不能空文件冒充成功。

E01.export_options结构：kinds[{export_kind,formats,availability,reason}]、contents[{code,label,availability,reason}]、required_contents、scope_types、redaction_profiles、anonymize_required、max_selected_trace_ids、permissions。原文/脱敏模式与导出授权独立校验；无原文导出权限不得通过redaction_profile=none绕过。全部产物采用同一最终脱敏策略。

manifest至少包括schema_version、batch_id、snapshot_id、projection_version、policy_version、created_at、content_scope、context_scope、filter_fingerprint、sample_count、event_count、contents、redaction_profile、anonymize_ids、ui_version、files[{path,mime_type,size_bytes,sha256}]。文件hash对应实际可下载字节。ZIP路径规范化防目录穿越；HTML转义、CSV内容防公式注入。必选产物失败导致任务失败；可选内容省略必须在warnings/manifest清楚说明。

## 9 E05 任务状态与 E06 下载

E04快速返回平台Task，非同步文件流；E05使用同一Task：task_id、status、progress（0—100或null）、error_message、result。result.kind=agent_trace_export，含batch_id/snapshot_id/projection_version/artifacts/warnings。artifacts每项含artifact_id/filename/mime_type/size_bytes/sha256/expires_at/scope_summary。只有succeeded且合法产物存在才显示下载成功；failed/cancelled不下载。

E06请求body={}，鉴权和幂等规则同平台；响应data={download_url,filename,expires_at}，短效票据有效期由服务端返回，不能前端猜测。当前前端downloadTraceTicket仅允许同源URL，Mock可blob；后端应返回同源授权下载代理地址，不要求前端放开任意第三方域名。实际文件下载是字节流，不能送入JSON request解包；使用现有受控下载工具，票据过期可重新领取。

不返回磁盘路径；签名票据、产物ID不可跨租户读。服务端控制文件名和响应Content-Type/Content-Disposition，成功产物与请求scope、内容版本一致。后台任务可继续执行，前端离开只停止轮询，不默认为取消任务。

## 10 错误与验收矩阵

| 条件 | 状态与处理 |
| --- | --- |
| 未登录/令牌失效 | 401；沿用共享跳登录逻辑 |
| 无批次/原文/导出权限 | 403或平台隐藏存在性404；不返回敏感字段 |
| 样本/事件不属scope | 404；不静默换对象 |
| 幂等键载荷冲突/版本写冲突 | 409；只重试原操作或重新查询 |
| 快照投影/游标/产物已过期 | 410及稳定reason_code；指导重新查询/领取 |
| 参数非法/过滤值不支持 | 422；含字段错误，不当成空结果 |
| 限流/临时故障 | 429/503，可提供Retry-After；前端显式重试 |
| 合法空样本集合/无证据 | 200，空列表或null selection，区分pending/unavailable |
| 局部来源丢失 | 200 partial，面板reason_code=source_unavailable；不编造内容 |

联调至少覆盖：

1. 不传view的旧接入契约、view=statistics以及execution互不破坏；旧上传绑定任务入口保持。
2. 初次按options → 默认批次dashboard → 默认样本overview自动加载，成功查询锁定scope；之后只切换下拉不请求dashboard，点击查询才更新；无可用批次不请求详情。查询不产生agent_trace_ingest或模型任务。
3. 两批次快速切换、相同ID不同快照、旧响应晚到均不会串数据。
4. 样本total200、当前页6、筛选命中数三口径正确；列表无N+1。
5. 18事件7调用由源记录推导；一次返回/重试/重复ID按调用尝试规则处理；缺失时间为null。
6. 图与日志ID一致，多证据/多模式正确定位，首个风险跨页可达；500以上图分页不丢边、不伪称完整。
7. Emoji、中文、换行及脱敏替换后的UTF-16高亮准确，Token与字符坐标分开。
8. 原文权限撤回、cursor换用户、跨租户artifact请求均被拒；缓存不泄露旧原文。
9. 回放已缓存页无逐节点HTTP；下一事件页批量返回selection_preview，失败暂停可重试。
10. PNG/ZIP为真实格式，范围和manifest一致，票据过期可恢复，任务失败不假成功。

最终联调记录应写明哪些API已实现、哪些仅Mock、后端能力注册状态及真实环境验证结果，不以截图相似作为业务完成证据。

## 2026-11-08 当前实现接口核对与自动下载补充

本节按当前页面、API 适配器、store/composable 和 TypeScript DTO 核对，区分现有调用与规划扩展；与前文历史交互描述冲突时以本节为准。接口齐备指前端调用及交接契约覆盖，不代表真实后端已经部署或完成联调。

### 当前视图导出闭环

1. `POST /tasks/execute`，`capability_code=agent_trace_export`。快速返回 JSON envelope 内的 Task，不直接返回文件。随后通过 `GET /tasks/{task_id}` 查询；立即成功和异步成功必须使用同一结果结构。
2. `pending/running` 返回 `progress`（0—100，未知可 null）；`failed/cancelled` 返回可展示的 `error_message`。仅文件已经生成并可读取时返回 `succeeded`、`progress=100`。同一任务的终态与产物 ID 保持稳定。
3. 成功结果必须含 `result.kind=agent_trace_export`、`batch_id`、`snapshot_id`、非空 `artifacts`。当前视图应返回一个 PNG 产物，字段至少为 `artifact_id/filename/mime_type/batch_id/snapshot_id`；生产还应返回实际 `size_bytes/sha256/expires_at`。PNG 的 MIME 为 `image/png`，文件内容必须是真实 PNG。
4. **最终代码流程已变更**：Task 成功且 artifacts 非空后，由 ViewExportStatus 调用 tracePagePng，对浏览器当前 .agent-traces DOM 生成 PNG，再以本地 Blob URL 自动下载。此入口目前不调用 download prop、不领取 download-tickets，也不读取后端 PNG 字节；artifacts[0].filename 仅参与文件命名。真实模式仍先提交/查询真实任务；Mock 模式使用演示任务。因此后端任务和渲染能力仍是入口前置依赖，不能因本地截图就省略任务接口或伪造成功产物。
5. ZIP 结果包及其他原有文件下载继续使用票据协议：POST download-tickets、body={}，返回 download_url/filename/expires_at，再 GET 同源字节流。文件 GET 使用 fetch(credentials=same-origin)，不添加 Bearer；需票据 URL 或会话授权，失败返回非 2xx。文件内容不是 JSON envelope，下载地址不能是磁盘路径或登录 HTML。
6. 当前状态栏将后端任务进度映射到 0—70%，本地 DOM 复制/图片编码为后续阶段，触发下载后到 100%；这不是后端 progress 原值，也不表示浏览器磁盘落盘已验证。后端仍只返回自己的真实 progress，不需改为页面组合百分比。

验收应分别验证真实任务、浏览器 PNG 和后端产物：任务失败/空 artifacts 不生成页面图；重复终态不重复下载；本地图片含 Canvas/SVG 和当前展示内容；ZIP 的票据 403/410 与字节流失败独立验证。截图完整性不等于后端 PNG 模板一致性，HTTP 联调必须关闭示例模式。

### 思维路径实际参数与兼容边界

E01—E06 已覆盖当前页面操作。首次 workspace(include=options) 后查询 workspace(include=dashboard,batch_id)，再取 section=overview；事件分页用 section=events/event_page，事件选择用 section=selection/event_id，展开图用 section=graph/graph_cursor。各分段必须保留当前 scope 和 trace_id，并返回相应 events/selection/graph 对象，不能仅返回无身份的裸数组。

当前导出 ui_state 实际发送 `event_page/page/graph_event_ids/redaction_mode`；示例中的 page_size/event_page_size 等是可扩展字段，不得设为当前客户端必填。缺失页大小沿用对应查询接口默认值。input 带 scope 中的 permissions_version，应重新验证权限；不能信任客户端权限版本跳过鉴权。

当前 PNG：scope.type=sample，trace_ids 恰好当前样本，contents=[execution_png]。scope 还可能携带列表的 q/language/risk_level/audit_decision/page/page_size；sample 范围以样本 ID 为准，page 不改变目标。ZIP 实际固定请求 normalized_json/evidence_index/manifest，支持 batch、filtered、sample；batch 忽略局部过滤，filtered 重新查询完整匹配集合，不受 page 限制。当前 UI 没有 offline_html 或 execution_png 的 ZIP 内容勾选，前文能力声明不代表已提供这些控件。

redaction_profile 为 standard 或原文模式下的 none；必须另验原文导出权限。当前按钮根据 permissions.can_export 启用，未读取 export_options 的逐项 availability，因此当前 HTTP 接入应提供已开放的 PNG 及上述 ZIP 内容；不能只返回 can_export=true 却让全部入口不可用。细粒度能力控制属于后续前端接入事项，不应误记为已完成。

前文空 overview 示例仅展示局部字段：实际还必须包含顶层 trace_id，summary 中的 language/risk_level/audit_decision/risk_types/event_count/call_count/duration_ms，以及 events/danger_patterns 的完整 PageResult。空数据提供 [] 或允许的 null，不能省略当前页面直接访问的对象。

## 最终页面响应依赖与已知边界（2026-11-08 复核）

| 操作 | 当前调用及必须返回 |
| --- | --- |
| 初次进入 | workspace?view=execution&include=options；必须有 batch_options.items 以及 permissions.can_query，否则无法继续自动查询 |
| 查询批次 | workspace?view=execution&include=dashboard&batch_id=…；返回 scope、sample_page、selected_trace_id、batch_summary、queried_at、permissions |
| 搜索/分页 | samples?view=execution，带固定 scope 和 q/language/risk_level/audit_decision/page/page_size；返回 PageResult，前端自动选首条 |
| 选中样本 | detail?view=execution&section=overview&redaction_mode=redacted；返回完整 Detail，核对 scope 和 trace_id |
| 选事件、上/下一步、回放 | 当前 events 页有目标则直接用 selection_preview；否则 section=selection&event_id=…；必须同时返回 selection 和目标所在 events 分页 |
| 事件翻页 | section=events&event_page=…；必须同时返回 events 和该页 selection，不能只给 events |
| 原文/脱敏切换 | 清空事件缓存后强制 section=selection，redaction_mode=raw/redacted；重新给 events（含对应模式的 selection_preview）及 selection |
| 加载图更多节点 | section=graph&graph_cursor=…；返回 graph.nodes/edges/total_nodes/complete/next_cursor，按 event_id/edge_id 去重合并 |
| 暂停、回放速度所涉及的时序 | 本地定时回放，每步从缓存或 selection 接口取结果，不需要后端“开始播放/暂停”接口 |

selection 分段的 scope.snapshot_id/projection_version 和 trace_id 必须与当前详情一致，否则被拒绝。events/selection 双返回是当前 store 的硬依赖；前文如仅列单一分段对象不能据此省略另一个。空 selection 允许 null，events 必须保留分页壳；跨页上/下一步依靠 previous_event_id/next_event_id，不以当前数组索引推断。

**跨页精确定位目前的限制：**工具页路由带 batchId/snapshotId/projectionVersion/traceId/eventId，但 execution.configure 当前只接 batchId/traceId/eventId；dashboard 请求未透传 snapshot/projection，也未传 trace_id。run 仅在 sample_page.items 含目标 trace_id 时选它，否则使用 selected_trace_id。因此非首屏目标、非当前快照的深链定位尚不能承诺完整支持。这是前端调用边界，后端仍必须坚持详情事件归属和固定版本校验，不得为绕过问题返回别的样本。需后续前端补传精确上下文才能覆盖任意样本深链，本次仅修订接口交接文档。

当前没有单独的危险模式分页操作，也没有对无限长原文分段内容的加载控件；pattern_page/content cursor 等扩展契约不应列为“页面已调用”。后端保留正确 totals/truncated/availability，不能把有限显示误报为全量。
