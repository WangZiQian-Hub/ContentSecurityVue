# 工具交互页前端实现与使用

更新：2026年11月8日。

## 使用

启动npm run dev，访问/compliance/agent-traces?view=tools。打开平台“示例演示”，选择AUD-2026-001，再选择AUD-0042 (EN)，点击查询。首次自动加载首个可用批次及首个样本的分析结果；此后修改条件，点击查询才更新。

页面包括当前结果、六张指标卡、耗时、时序图、调用表、选中调用详情、权限比较、错误归因和低效证据。点击图或表可联动详情；默认选CALL-05。定位思维步骤跳转execution并携带scope/eventId。原始事件以脱敏纯文本显示。改变查询条件不覆盖已展示结果，导出禁用直到重新查询。

## 文件与接口

- src/views/compliance/components/agent-traces/ToolsView.vue：查询、局部状态、图/表/详情、抽屉与导出。
- src/views/compliance/AgentTraceAuditPage.vue：tools页入口、父级旧watcher隔离、导出代理。
- src/types/agent-trace-tools.ts：独立tools DTO。
- src/api/agent-trace-tools.ts：复用平台request和旧资源URL的tools投影。
- src/mock/agent-trace-tools.ts：200个可搜索样本、空批次、无调用/缺时间/原文无权/长轨迹示例。
- src/mock/agent-trace-tools.test.ts：状态统计、分页、跨范围与原文权限测试。

仅改ContentSecurityVue目录。没有改动外部doc及后端项目。保留原有工作区改动。HTTP模式失败直接显示错误，不回退Mock。后端接入详见同目录《工具交互-后端接入使用文档》。

## 当前限制

这是可运行的基础实现，尚未达到所有目标细则和严格像素级一致：时序图使用按序分行的压缩展示，显示真实相对时间标签；真实时间比例、完整返回泳道和阻断符号需进一步打磨。选择器续页、原文授权切换、正文分段、跨段双向定位和导出能力白名单未全部实现。Mock PNG为数据摘要，ZIP为当前overview，长轨迹全量包仍需完善。真实后端接口尚待联调。完整目标协议保留于后端接入文档。

## 默认展示与查询时机调整（2026年11月8日）

本节替代上文及历史契约中“初次只加载选项、不自动查询”的要求。首次进入或切换演示/真实模式时：先GET workspace(view=tools,include=options)，取返回批次列表首项；再GET workspace(batch_id=选中批次)，解析candidate_scope及sample_options首项；最后GET样本详情section=overview并展示结果。Mock首样本为AUD-0042。真实模式完全使用服务端选项，不硬编码演示ID，不失败回退Mock。

后续切换批次只刷新候选scope和样本选项，并默认选该批次首样本；旧结果保留且提示条件未提交。切换样本同样不刷新分析，点击查询后才提交新结果。不存在可用批次或样本时显示明确空态，加载中显示骨架，错误展示错误说明。

接口路径、参数、字段、鉴权和响应结构均不变，无需新增后端接口；仅前端请求时机变化。后端应稳定返回已授权批次/样本排序，workspace(batch_id)按原协议返回首段sample_options与candidate_scope，overview返回对应已发布版本。此页仍是样本工具调用分析，默认显示批次下代表样本，并非把单样本统计伪装为整批汇总。

## 思维步骤跨页定位修复（2026年11月8日）

原因：tools Mock过去为AUD-0042生成mock_trace_42/event_12，而execution Mock的同一展示样本实际为mock_trace_0/mock_trace_0_event_12，且两者快照版本不同。现在工具交互Mock复用executionSamples的样本主键与展示ID，事件使用同一样本的完整event_id，snapshot_id和projection_version也保持一致；不修改思维路径的查询或页面代码。工具调用步骤不会超过对应样本的真实事件数。边界测试样本名称随共享样本清单展示，不再使用旧独立编号。

HTTP接口没有变化；后端应保证不同view投影的同一batch/snapshot/projection/trace/event使用相同稳定主键，不能用STEP-12展示文本代替event_id。locate仍透传已查询scope、trace_id、event_id，不能在HTTP模式拼接或猜测ID。

新增回归：200个Mock样本的工具调用均可被execution详情识别；浏览器实测CALL-05定位到AUD-0042的STEP-12，日志选中mock_trace_0_event_12，截图tools-step-location.png。执行命令node scripts/agent-trace-tools-location-check.cjs。
