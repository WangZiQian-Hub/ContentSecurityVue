# 思维路径页面实现与使用

入口：`/compliance/agent-traces?view=execution`。使用现有平台外壳、四页签、蓝色按钮与父级演示开关。

## 操作

进入页面后自动展示默认批次的结果：先加载批次选项，优先使用URL明确指定的batchId，否则使用服务端选项列表中的第一项，再自动读取该批次摘要、当前页6条样本和默认样本详情。URL中的traceId/eventId可在此过程恢复定位。没有可用批次时显示“暂无可查询批次”；自动查询失败保留批次选择器和错误提示，可点击查询重试。

列表可搜索编号或风险类别，筛选语言、等级、审计状态；分页不改变批次总量。首屏自动加载仅在进入页面或切换数据模式时执行。之后选择新的批次只修改待查询条件，仍保留上次结果；点击“查询”后才更新结果，未查询期间禁止导出。

点击“应用筛选”后，条件区域自动收起并更新列表，已选择的语言、风险等级和审计状态保留；再次点击筛选图标可展开查看或修改条件。

“样本检索与列表（数量）”显示接口返回的列表总数：首屏为E01的sample_page.total，筛选或分页后为E02的total。未筛选时表示当前批次的可访问样本总数，筛选后表示命中总数，不再显示当前页items.length。批次摘要的sample_count仍表示整批规模，两者可不同。分页大小读取响应page_size；分页按钮固定收在本面板底部，样本卡片及展开的筛选控件在面板中间区域滚动，避免分页栏溢出边框。

点击路径节点、日志行或危险模式可定位同一事件并更新来源、内容和证据。路径根据后端edges绘制连接，实线表示sequence，其他关系使用虚线。长图分段加载。历史回放默认每秒一步，首个风险可跨日志页定位；操作不会触发外部工具执行。原文切换受权限限制，默认脱敏。

右上当前视图导出PNG；结果包可选整批、筛选集合或当前样本。HTTP使用平台异步任务与同源下载票据。Mock使用项目已有PNG/ZIP工具生成真实格式文件。

批次标签、下拉框选中值、查询按钮及结果说明条统一为14px左右，控件高度32px，保持与前两个子页面相近的表单密度。样式限定在`.at-execution`内。

点击“导出当前视图”后，先在查询区上方显示与统计页相同形式的导出状态条和进度。任务成功后自动收起进度条，仅保留任务状态和下载按钮；Mock视图文件统一为“下载 agent-trace-view.png”，真实模式保留后端返回的产物文件名，由用户点击下载。生成阶段不会自动下载。Mock模拟pending、running和succeeded阶段，图片生成失败显示failed；真实模式使用后端Task.progress，未提供进度时使用不确定进度条。任务长时间未结束可恢复进度查询，下载失败可再次点击下载。离开页面或切换Mock/HTTP模式时清理当前观察和未下载的Mock文件。状态栏的背景、字体、间距、边框及圆角与统计指标页保持一致。

## 文件组织

- `src/types/agent-trace-execution.ts`：前端camelCase DTO。
- `src/api/agent-trace-execution.ts`：三个既有领域资源的execution投影，使用共享request。
- `src/mock/agent-trace-execution.ts`：200条可分页fixture、空批次、620事件长轨迹、缺失时间与原文禁止场景。
- `src/stores/agent-trace-execution.ts`：查询/详情请求序号、scope、事件缓存、原文切换及回放生命周期。
- `ExecutionView.vue`：查询、三列面板、日志与导出。
- `ExecutionGraph.vue`：SVG路径图；节点可键盘定位。
- `src/composables/useExecutionExport.ts`：本页独立的导出进度、任务轮询、产物下载及取消清理，其他页面继续使用各自原有实现。
- `AgentTraceAuditPage.vue`：execution组件接入及导出按钮委托；旧接入/统计/工具视图仍使用原分支。

## 后端接入

切换父级到真实接口模式，配置现有VITE_API_BASE_URL与平台登录身份。所有请求自动携带`view=execution`，scope固定snapshotId与projectionVersion；HTTP失败不会降级成Mock。

后端先阅读[后端接入使用文档](./智能体轨迹审计-思维路径-后端接入使用文档.md)，完整目标规范见[接口完整契约](./智能体轨迹审计-思维路径-后端接口完整契约.md)。完整契约中07/08的相对链接指向原始需求目录，项目内使用本实现说明和接入文档即可。

## 当前实现边界

已实现常用overview/selection/graph读取与事件页缓存回放。超长Selection的selection_cursor追加、危险模式独立翻页、批次远程选项翻页仍需补齐；当前选择器在已返回的批次选项中本地搜索。时间显示沿用浏览器zh-CN格式。Mock导出PNG使用项目既有文本报告渲染工具，并非页面像素级截图；ZIP包含样本摘要与当前样本的证据索引，尚未生成整批每条样本的完整事件明细。真实HTTP的最终产物由后端任务生成。

Mock文件仍在前端生成，但现在带有本页的任务状态和进度展示，并能处理生成失败；这些阶段仅为演示，不代表连接后端排队服务。真实模式完整保留E04—E06。完整目标规范中更广的导出能力声明与脱敏策略协商需后续联调补齐。上述边界不应被视为后端已实现，也不能将摘要ZIP当完整原始轨迹档案。
