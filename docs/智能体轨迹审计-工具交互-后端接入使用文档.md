# 智能体轨迹审计 · 工具交互 · 后端接口与数据细则

日期：2026年11月7日。配套：[前端实现说明](./智能体轨迹审计-工具交互-前端实现与使用.md)。本文件定义目标接口扩展，不表示后端已经实现。后端团队另行实施；前端代码任务不得修改ContentSecurityVue之外目录。

## 1 资源设计与兼容

复用已核实前端agent-traces资源，增加显式`view=tools`。不传view的旧接入协议不变；statistics、execution继续各自协议。旧createBatch/upload/bind/execute/task/ticket全部保留，不因新增tools替换旧响应。

| 编号 | 方法与路径（统一前缀/api/v1） | 职责 |
| --- | --- | --- |
| T01 | GET /compliance/agent-traces/workspace | 批次选项、候选快照、首段样本选项、能力 |
| T02 | GET /compliance/agent-traces/batches/{batch_id}/samples | 样本选项分页搜索 |
| T03 | GET /compliance/agent-traces/batches/{batch_id}/samples/{trace_id} | 一个样本的工具审计复合详情及有界投影 |
| T04 | POST /tasks/execute | 复用agent_trace_export异步能力 |
| T05 | GET /tasks/{task_id} | 任务进度和产物 |
| T06 | POST /compliance/agent-traces/artifacts/{artifact_id}/download-tickets | 授权下载票据 |

共6个HTTP操作，不为统计数字、泳道、调用、权限比较项、单条证据新建URL。T03 section用于同一资源的有界投影。后端内部批量查询/连接获取相关数据，避免一行一次远程RPC或N+1数据库查询。分页/完整文本按需读取，不把整批所有轨迹一次塞给浏览器。

## 2 平台公共约束

请求/响应wire字段snake_case；前端request自动转换camelCase并解包data，API适配器不重复转换。统一JSON响应：

```json
{"code":0,"message":"ok","data":{},"trace_id":"http_trace_01","timestamp":"2026-11-07T09:00:00+08:00"}
```

code=0成功，错误code走平台注册体系，不在本页发明数字错误码。HTTP错误使用正确状态和同类envelope，不把鉴权错误伪装200；不返回共享request无法处理的204。envelope.trace_id是请求追踪号，data.trace_id是业务样本号。

Authorization Bearer、X-Request-Id、X-Trace-Id沿用平台。所有POST遵循前序文档幂等约定：用户+方法+路径+X-Request-Id，同键同载荷返回同结果、不同载荷409；至少保留24小时，重放仍验证权限。同一网络重试沿用键，新业务动作换键。任务提交快速返回，不同步生成大型ZIP。

分页为`{items,total,page,page_size,total_pages}`，page从1，total_pages=ceil(total/page_size)。空集合page=1、total=0、total_pages=0。合法超末页空items且真实total；非法参数422。计数为非负安全整数，未知为null；0与缺失严格区分。时间ISO8601带时区，持续时间统一毫秒且非负。

availability枚举available/partial/unavailable/not_applicable，附reason_code/reason。权限不足、尚未审计、源缺失、无需适用分别表达。任意原始JSON必须使用input_json/output_json/raw_text字符串，避免前端递归改键；动态维度返回数组而不是以源字段名作为对象键。文本全部按不可信内容处理。

## 3 范围、身份与版本

固定scope字段：batch_id、snapshot_id、projection_version、schema_version、policy_version、permissions_version。snapshot为不可变解析快照；projection包含审计规则输出版本，修改结论必须发布新版本。候选scope来自T01，T02及首次T03沿用；查询成功成为appliedScope，后续分页、详情、原文、导出全部沿用。旧版本回收返回410，不暗换最新版本。

所有业务关系校验包含租户、用户、batch、snapshot、trace、call、event、artifact。batch_id/trace_id/call_id是内部稳定ID，display_id仅展示；不允许按CALL-05文本猜主键。call_id标识规范化调用尝试，重复源ID另存source_call_id；真实重试独立call_id/attempt_id并有parent_call_id。一次请求及其返回不能算两次调用。

event_id在样本中稳定唯一，step_display_id/ordinal只做展示与排序。tool_id是规范工具身份，同名不同工具不可误并，策略引擎默认participant而非工具。测试类别与风险审计结论分开；risk_level=high/medium/low/none/unknown，audit_decision=risk_found/no_risk_found/pending/error/unknown，未知或待审计不能自动none。

## 5 T02 样本选项

必传view=tools、snapshot_id、projection_version；path含batch_id。q默认空，最长100，按display_id和授权名称搜索；language=all/zh/en/other/unknown，默认all。page=1/page_size=50，最大100。大小写不敏感，空白trim，查询参数化。不能对未授权原文全文检索。

data为PageResult并加context={scope,q,language,sort}，固定排序ingest_order ASC、trace_id ASC。items字段：trace_id、display_id、language、source_id、source_format、ingest_order、availability、reason、allowed_actions（view_detail布尔）。允许返回test_category/risk_level作为轻量辅助，但不返回全文或完整调用。total是筛选后样本数，不能用批次总量冒充。选中项不在搜索页时前端保留T01.selected_sample或已选缓存，不自动换选。

## 6 T03 复合详情与分段

### 6.1 通用请求

必传view=tools、snapshot_id、projection_version；path batch_id/trace_id必须归属一致。redaction_mode=redacted/raw，默认redacted；raw无权限403。call_id可选，用于定位。call_page=1、call_page_size=20（20/50/100）；sequence_cursor可选不透明游标。section默认overview。

| section | 必返内容 | 用途 |
| --- | --- | --- |
| overview | scope/trace_id/summary/metrics/timing/sequence/calls/selection/sample_analysis/permissions/export_options/availability/warnings | 查询一次取得主要面板和默认详情 |
| calls | scope/trace_id/calls/selection_policy | 列表翻页，不重复统计大图；不自动变更当前selection |
| sequence | scope/trace_id/sequence | 时序图续段；不返回全量原文 |
| selection | scope/trace_id/selection/locator | 选中调用完整有界详情、原始事件、跨页定位 |

所有section返回自身scope/trace_id，客户端必须校验。selection必须call_id，否则422；未知call_id或跨样本404，不能自动选其他调用冒充成功。overview不传call_id按首个denied且not_executed、首个failed、第一调用顺序默认选；显式call_id则优先且验证。overview的calls页和sequence段包含默认/显式选中调用；无调用两者空、selection=null。

overview只读，不产生agent_trace_ingest/模型执行任务。不支持的section或参数组合422。section=selection可传include_raw=true（默认false）；raw_page=1、raw_page_size=20最大50；raw_event_id可选定位当前调用关联事件，content_offset=0、content_limit=16384最大65536 UTF-16单位，用于单条大型正文续段。只有include_raw=true时这些参数生效，不支持时应拒绝而非默默忽略。

### 6.3 metrics与统计口径

metrics={call_count,tool_kind_count,success_count,error_count,not_executed_count,unknown_status_count,overreach_count,inefficient_count,availability,reason}。

统计范围为完整样本全部规范化调用尝试，完全不随分页、图分段、选中调用变化。执行状态互斥：succeeded/failed/not_executed/unknown；完整数据时call_count等于四类之和。越权与低效来自behavior_tags，是可重叠维度，按不同call_id去重，不能与成功/失败求和。一次调用命中三条越权证据仍计1。工具种类按实际被请求的tool_id去重，包括被拦截尝试，但不把policy participant计入；未识别tool_id数量单独warning说明，不能虚构种类。

行为标签overreach/inefficient，normal仅当审计完整且无异常标签。越权标签可与succeeded同时出现（系统发现越权但策略未拦截），不能前端强制未执行。结果为failed但权限allowed时属于工具错误而非必然越权。审计未完成的行为计数可null并标partial，不把0解释为安全。

### 6.4 timing

字段：total_duration_ms、tool_duration_sum_ms、tool_wall_time_ms、other_duration_ms、has_overlap、duration_source、coverage、availability、reason。duration_source=explicit/derived/not_provided；coverage=complete/partial/unknown。

- total是样本实际起止间隔，或可信显式持续时间，不是调用耗时相加。
- tool_duration_sum是已执行调用duration的累计值；部分缺失只能是部分和，coverage说明。
- tool_wall_time是样本范围内已执行调用时间区间的并集长度，处理并行，不重复累加。拦截且未执行不占工具执行时长；策略耗时属于其他处理。
- 仅可靠总时长与完整工具区间存在时，other=total-tool_wall_time；不满足则null。不能减工具累计值导致负数；时间区间越界应报质量warning而非偷偷裁剪掩盖问题。
- 未执行duration_ms=null，真实瞬时执行0有效；没有时间戳可有duration，但不能据此构造相对起止轴。

示例7调用耗时210、480、462、403、null、320、3125累计5000ms；可构造不重叠区间[0,210]、[210,690]、[690,1152]、[1152,1555]、拦截时刻2010、[2010,2330]、[5460,8585]，样本总时长8600ms，则工具占用5000、其他3600。该时间是Mock可复现示例，不宣称截图旧轴准确。生产必须来源于真实记录，不能为凑8.6秒编造日志。

### 6.5 sequence

结构：participants、items、total_calls、loaded_calls、complete、next_cursor、segment_start_cursor、time_basis、availability、warnings。time_basis=relative_time/ordinal；loaded_calls表示截至当前游标的累计数量，若是定位跳段须另返segment_offset，前端使用实际缓存计数而非宣称前段均已加载。

participant字段participant_id、kind(agent/tool/policy/unknown)、label、tool_id可null。items每项按call聚合：call_id/display_id/order、from_participant_id、to_participant_id、decision_participant_id可null、relative_start_ms/end_ms/decision_time_ms可null、duration_ms、execution_status、behavior_tags、action_label、return_label、request_event_id、return_event_id、decision_event_id、locator。

每段最多200调用，participant列表只含当前所需并支持按稳定ID合并；同ID属性冲突视版本错误。cursor绑定scope/trace/排序/权限/脱敏，服务端签发，不能客户端拼offset猜游标；过期410。稳定排序(order ASC,call_id ASC)，order为规范记录顺序，与时间排序差异要标识，缺时间不伪造。每次调用只出现一段，调用及其返回在同项中，避免跨段丢边。选择详情返回目标段起始cursor，首段为null。

### 6.6 calls分页与预览

calls为PageResult，items每行字段如下：

| 字段 | 类型/说明 |
| --- | --- |
| call_id/display_id/order | 稳定身份和展示顺序 |
| source_call_id/attempt_id/parent_call_id | 源标识与重试关联，可null |
| tool_id/tool_name | 规范工具标识/显示名 |
| event_id/step_display_id | 可定位步骤，不解析STEP字符串生成ID |
| duration_ms/execution_status | 耗时与四类状态 |
| behavior_tags | [{code,label}]可重叠 |
| input_summary/output_summary | 已脱敏纯文本，各最大512字符并有截断标志 |
| result_code | 如POLICY_DENIED，不由前端拼造 |
| evidence_chain | [{event_id,display_id,relation}]，最长50并标truncated |
| locator | {call_page,call_page_size,sequence_cursor,event_id}；绑定本次page_size |
| selection_preview | 下节selection的有界预览，不含原始事件全文 |

每行preview提供足以切换详情/权限/归因的内容：input_json/output_json各最多4096 UTF-16单位，权限比较最多20行、证据最多20条；truncated_fields显式列出。禁止截断半个代理对，文本如截断后不再是合法JSON则用代码文本展示并标注截断，不能JSON.parse假设完整。overview默认selection是完整有界详情，其他行无需逐条请求。

### 6.7 selection及分析

selection字段：call_id、display_id、tool_id、tool_name、event_id、step_display_id、execution_status、duration_ms、permission_decision、granted_scopes、requested_scopes、result_code、evidence_chain、input_json、output_json、analysis、locator、raw_events可选、content_version、redaction_profile、permissions_version、truncated_fields、allowed_actions、availability。

permission_decision=allowed/denied/unknown/not_applicable；权限范围为字符串数组。input_json/output_json完整有界内容各最多65536 UTF-16单位，超限显式truncated，完整可下载授权结果包或原始事件分段。allowed_actions={can_locate_step,can_view_raw,can_copy,can_export}及reason；服务端仍逐请求鉴权，不信前端布尔。

analysis.permission_comparison={rows,actual_decision,policy_version,availability,reason}；row含dimension_code/label、granted、requested、comparison(match/mismatch/unknown/not_applicable)、evidence_refs。granted/requested为展示文本或数组，类型在schema固定，建议统一字符串数组。actual_decision={decision,code,message}。

analysis.error_attribution={phase,code,message,rule_id,rule_version,policy_version,evidence_refs,availability}或null。phase=pre_execution/tool_execution/post_execution/unknown；策略拦截与接口执行失败分开，不用“接口错误”统称拒绝执行。

sample_analysis返回当前样本级inefficiency_groups、availability、reason；每组group_id、canonical_call_id、duplicate_call_ids、reason_code、reason、comparison_basis、evidence_refs、suggestion。若组数多，最多100，返回total/truncated及export_full_available；不悄悄截断。超出部分通过全量结果包查看，本版不新增分页URL。selection.analysis.related_group_ids用于高亮当前调用相关组。

重复判定至少结合规范工具身份、规范化参数、上下文/权限范围与缓存有效期；相同搜索词不等同所有环境都可复用。示例CALL-03重复CALL-02，CALL-06重复CALL-01；两组不能互相混为同一请求。没有足够证据仅标疑似并给confidence/availability，不能确定指控。

证据结构统一evidence_id、event_id、rule_id、rule_version、policy_version、source_ref、summary、content_version；source_ref含source_id/record_index/path/line_start/line_end，缺失可null，不能给浏览器可执行本地文件路径。

### 6.8 原始事件

include_raw=true返回raw_events分页，每项event_id/event_type/source_ref/raw_text/content_version/redaction_profile/availability/truncated/content_offset/returned_length/total_length/next_offset。关联事件来自真实调用链，可能包含request/return/policy_decision多条，不能认为CALL对应唯一事件。

raw_event_id不传时各项返回首段，传时只对目标关联事件应用content_offset/content_limit并提供分页locator；跨调用事件ID404。偏移单位UTF-16，offset不得落在代理对中间，非法422；服务端返回实际next_offset。content_version和redaction_profile变化后旧offset作废409或410，客户端清正文重新读取。转义展示，原文授权和导出原文授权分别校验，不先下发原文再靠CSS遮盖。来源丢失返回availability=unavailable而非捏造JSON。

## 8 错误、授权与缓存

| 场景 | HTTP和处理 |
| --- | --- |
| 令牌失效 | 401，共享request处理登录 |
| 无资源/原文/导出权限 | 403或平台存在性隐藏404，不返回敏感正文 |
| 样本/调用不属scope | 404，不返回另一个样本 |
| 幂等载荷冲突、正文版本变化 | 409，给稳定reason_code |
| 快照/投影/游标回收 | 410，重新选项查询；不静默最新 |
| 参数、section、ID组合非法 | 422，字段错误可读 |
| 限流/临时故障 | 429/503，允许Retry-After |
| 合法零调用 | 200，metrics为真实0、sequence/calls空、selection=null |
| 局部来源缺失 | 200 partial+面板原因，其他面板仍可用 |

缓存至少按用户/租户、mode、scope、trace_id、权限版本、脱敏模式、content_version、section参数分隔。权限撤销即时阻断后续读取和下载，不能仅靠旧快照授权。ETag/304若引入需与共享request能力协商，本版不要直接返回其无法解包的裸304。日志不记录未脱敏工具输入、票据和原文；保留trace_id诊断。

## 2026-11-08 当前实现接口核对与自动下载补充

本节按当前页面、API 适配器、store/composable 和 TypeScript DTO 核对，区分现有调用与规划扩展；与前文历史交互描述冲突时以本节为准。接口齐备指前端调用及交接契约覆盖，不代表真实后端已经部署或完成联调。

### 当前视图导出闭环

1. `POST /tasks/execute`，`capability_code=agent_trace_export`。快速返回 JSON envelope 内的 Task，不直接返回文件。随后通过 `GET /tasks/{task_id}` 查询；立即成功和异步成功必须使用同一结果结构。
2. `pending/running` 返回 `progress`（0—100，未知可 null）；`failed/cancelled` 返回可展示的 `error_message`。仅文件已经生成并可读取时返回 `succeeded`、`progress=100`。同一任务的终态与产物 ID 保持稳定。
3. 成功结果必须含 `result.kind=agent_trace_export`、`batch_id`、`snapshot_id`、非空 `artifacts`。当前视图应返回一个 PNG 产物，字段至少为 `artifact_id/filename/mime_type/batch_id/snapshot_id`；生产还应返回实际 `size_bytes/sha256/expires_at`。PNG 的 MIME 为 `image/png`，文件内容必须是真实 PNG。
4. **最终代码流程已变更**：Task 成功且 artifacts 非空后，由 ViewExportStatus 调用 tracePagePng，对浏览器当前 .agent-traces DOM 生成 PNG，再以本地 Blob URL 自动下载。此入口目前不调用 download prop、不领取 download-tickets，也不读取后端 PNG 字节；artifacts[0].filename 仅参与文件命名。真实模式仍先提交/查询真实任务；Mock 模式使用演示任务。因此后端任务和渲染能力仍是入口前置依赖，不能因本地截图就省略任务接口或伪造成功产物。
5. ZIP 结果包及其他原有文件下载继续使用票据协议：POST download-tickets、body={}，返回 download_url/filename/expires_at，再 GET 同源字节流。文件 GET 使用 fetch(credentials=same-origin)，不添加 Bearer；需票据 URL 或会话授权，失败返回非 2xx。文件内容不是 JSON envelope，下载地址不能是磁盘路径或登录 HTML。
6. 当前状态栏将后端任务进度映射到 0—70%，本地 DOM 复制/图片编码为后续阶段，触发下载后到 100%；这不是后端 progress 原值，也不表示浏览器磁盘落盘已验证。后端仍只返回自己的真实 progress，不需改为页面组合百分比。

验收应分别验证真实任务、浏览器 PNG 和后端产物：任务失败/空 artifacts 不生成页面图；重复终态不重复下载；本地图片含 Canvas/SVG 和当前展示内容；ZIP 的票据 403/410 与字节流失败独立验证。截图完整性不等于后端 PNG 模板一致性，HTTP 联调必须关闭示例模式。

时序加载按数组直接拼接，没有对 call_id 去重，因此服务端 next_cursor 返回的下一段不得重复上一段调用；complete=true 时 next_cursor=null。同一个调用若同时出现在 calls 与 sequence 中，身份、权限判定和预览必须一致，不能由于分段返回不完整而让本地点击显示 undefined。

工具页 can_export 当前只影响导出；can_view_raw 控制原文按钮。后端不得依赖前端隐藏按钮完成授权。授予当前页面可查询权限时仍需提供全部展示用面板壳；拒绝请求返回明确错误，不能将 403 伪装成零调用样本。
