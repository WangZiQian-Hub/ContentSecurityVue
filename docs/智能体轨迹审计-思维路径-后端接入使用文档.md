# 思维路径后端接入使用文档

该文件可直接交给后端同学。前端代码已接入既有URL的execution投影，前端不修改后端代码。字段完整解释参见[完整契约](./智能体轨迹审计-思维路径-后端接口完整契约.md)，类型实现见`src/types/agent-trace-execution.ts`。

## 最小接入顺序

1. 实现GET `/api/v1/compliance/agent-traces/workspace?view=execution&include=options`，返回batch_options分页。前端进入页面后先调用此请求，选择URL指定批次或选项第一项作为默认批次。
2. 首屏选定默认批次后，前端自动调用同地址include=dashboard并传batch_id；之后用户选择其他批次必须点击“查询”才再调用。返回scope、batch_summary、sample_page、selected_trace_id、queried_at、permissions。scope包含batch_id/snapshot_id/projection_version/permissions_version。仅修改下拉值不会发起dashboard请求。
3. 实现GET `/api/v1/compliance/agent-traces/batches/{batch_id}/samples`，处理q、language、risk_level、audit_decision及page/page_size。返回真实total，不把6条当前页当整批。

   标题数量直接取该分页结构的total：首屏使用工作区sample_page.total，后续使用本接口total。total必须是当前授权批次、快照和筛选条件下的样本总数；items仅是当前页，page_size为服务端实际页大小。前端不会用items.length或页码推算总数，也不为这个数字另建接口。未筛选时示例标题为“样本检索与列表（200）”，单样本检索命中时可为“样本检索与列表（1）”。
4. 实现GET同一路径`/{trace_id}`，section=overview一次聚合summary、graph、events、selection、risk_distribution、danger_patterns、first_risk_event_id和permissions。section=selection返回目标所在events页和selection；graph返回下一图段。所有请求显式view=execution。
5. 平台POST `/api/v1/tasks/execute`注册agent_trace_export，支持input.view=execution、export_kind=view/package、format=png/zip、固定scope、selected_trace_id/selected_event_id、ui_state和redaction_profile。
6. GET `/api/v1/tasks/{task_id}`返回标准平台状态和result.artifacts；POST `/api/v1/compliance/agent-traces/artifacts/{artifact_id}/download-tickets`返回download_url、filename、expires_at。下载URL须为同源文件代理。

本次首屏自动展示不新增接口、不放宽dashboard的batch_id必填要求、不增加响应字段。调用顺序为options → dashboard → 默认样本overview（若有样本）；均读取已有结果，不创建审计或解析任务。若无可选批次或can_query=false，不继续自动查询；选项第一项作为默认批次，后端应按既有稳定排序返回授权范围内的选项。

导出当前视图：真实模式仍先提交/查询 E04/E05，成功且 artifacts 非空后在浏览器本地绘制当前页面 PNG 并自动下载；目前不调用 E06，不下载后端 PNG 字节。ZIP 结果包仍经 E06 领取同源票据下载。图片内容与后端任务产物不是同一个文件，最终实现边界见[完整契约末尾复核说明](./智能体轨迹审计-思维路径-后端接口完整契约.md)。

## 传输约束

HTTP使用snake_case，前端统一request自动递归转camelCase并解包data。成功返回`{code:0,message:"ok",data:{...},trace_id:"HTTP追踪号",timestamp:"ISO时间"}`。认证沿用Bearer；X-Request-Id用于写接口幂等，X-Trace-Id用于HTTP追踪。data.trace_id是样本ID，与外层追踪号不同。

原始JSON、工具参数和结果作为字符串传输，不把任意用户键放DTO对象里。ID以服务端返回为准；事件ordinal用于顺序，展示编号只展示。缺失时间/置信度为null，不能补0。一个工具调用的结果事件不能再算一次工具调用。

scope在一次查询周期内不可变。事件必须属于当前样本、样本属于指定批次快照；版本失效410，不静默换新版本。原文权限由后端控制，返回脱敏文本不能夹带隐藏原文。高亮位置相对返回文本按UTF-16半开区间[start,end)计算。

## 当前前端实际消费字段

- workspace：scope、batch_options.items、batch_summary.sample_count/by_language、sample_page、selected_trace_id、queried_at、permissions.can_export。
- sample：trace_id、display_id、language、risk_types、risk_level、audit_decision、event_count、call_count、duration_ms。
- detail：graph.nodes/edges/next_cursor/total_nodes，events标准PageResult，selection及各事件selection_preview；risk_distribution.items；danger_patterns标准PageResult；permissions.can_view_raw/can_export。
- selection：event_id/display_id/ordinal、previous_event_id/next_event_id、content.source_excerpt/reasoning_summary（text/highlights）、risk_evidence.items、lineage.nodes。
- evidence：evidence_id/risk_type/match_pattern/severity/rule_id/review_status/confidence/related_call_ids。

这些是当前组件读取的最小集合，完整契约要求的版本、availability、cursor、安全字段仍建议完整返回，以支持后续扩展。不要删除旧接入或统计投影字段，也不要改公共request契约来适应本页。

## 联调验收

先用一个18事件、7调用的完整样本验证图/日志/证据同ID，再验证空批次、无权限、无风险、未审计、缺时间和500以上节点。样本搜索与分页一次取一页；回放已缓存事件不逐条调用HTTP。检查导出范围不受当前页6条限制，ZIP/PNG为真实格式，失败任务不得返回假成功产物。

本次只完成前端实现与Mock验证，没有声明后端接口已联调通过。原文/扩展分段、批次远程选项及全量导出明细的当前前端边界见[实现与使用](./智能体轨迹审计-思维路径-前端实现与使用.md)。


## 最终代码复核提醒

options 响应必须包含 permissions.can_query；selection 和 events 两种分段均必须同时返回 events 与 selection。精确深链目前存在目标样本不在首屏及历史版本未透传的前端限制，详见完整契约末尾，不能据此要求后端放松事件归属校验。本文为接入入口，详细字段及当前实现边界以完整契约的最终页面复核章节为准。
