# 思维路径 Mock 批次兼容修复

现象：从前两个子页面携带batchId=mock_batch_demo进入思维路径，批次下拉显示内部ID，列表返回200条摘要，但详情报“样本不存在”。

原因：前两个子页面的示例批次为mock_batch_demo，本页早期独立fixture使用mock_batch_1；本页列表没有严格校验批次，错误地为未知批次也返回示例摘要，而详情只接受mock_batch_1，造成列表与详情范围矛盾。属于前端Mock兼容缺陷，不涉及后端解析或真实数据丢失。

修复仅在思维路径Mock及其状态中进行：

- 使用mock_batch_demo作为标准示例批次，选项标签保持AUD-2026-001。
- 将已知旧ID mock_batch_1作为兼容别名解析，URL恢复时也归一为标准批次。
- 工作区、列表、详情采用同一批次校验；未知批次报“批次不存在”，不返回其他批次的数据；空批次不允许读取默认批次样本详情。
- 返回的scope、样本详情和选择器保持一致。

真实HTTP接口未改动，真实batch_id不进行上述Mock别名转换；其他子页面、后端文件和环境配置未修改。新增单元回归覆盖跨页标准ID、旧别名、未知批次及空批次归属；浏览器脚本使用`view=execution&batchId=mock_batch_demo`作为入口。

如浏览器仍保留修改前的运行状态，刷新页面后重新进入即可加载统一后的Mock数据。
