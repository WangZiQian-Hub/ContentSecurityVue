本次范围为数据处理、数据价值分析、异常数据治理、风险识别与分级。数据质量评估仍为未开放页签，没有实现独立页面或伪造质量评估结果。其他模块页面及样式不作修改。

## 数据关系与统计口径

共享的是 `datasetId → versionId → sampleId / language / text`，各模块保留独立方案和结果。查询分析结果还必须限定 `language + schemeId`。不同子页的 `resultId`、评分、风险和异常候选不能互相替代。

- 六个基础演示数据集各有完整 120 条资源样本；不存在用 preview 冒充全量的分页。
- 数据集 3 的基础版本 `dsv_000003`：全部语种 120 条，中文 41 条。同为中文范围时，价值分析的目标样本、异常检测有效样本、风险检测有效样本均为 41；价值评分不可评估项单独计数。
- 价值分析及异常页初始语种为中文；风险页初始为全部语种。因此原截图中 41 与 120 的差异来自明确的筛选范围，不能直接对比。语种选项和结果栏现在均显示中文名称。
- 风险候选 2 与异常候选 39 属于不同业务含义：风险针对内容语义，异常针对标签等数据问题，不能要求两者相等。风险按样本最高建议等级去重，人工结论与模型/规则建议分开。
- 分析、风险检测均不自动改写正文；异常修复生成新版本。新版本出现在目录并不表示已经评分或检测，没有该版本保存结果时显示“无结果”，需要显式分析/检测。
- 演示修复版本仅在当前页面会话内存在，刷新浏览器会重置。不会把 mock 的会话操作描述为后端持久化。

## 接口来源与接入状态

### 共用资源入口

新增 `src/api/governance-resources.ts`，四个模块的 options 通过该入口合成资源目录。各模块 options 中旧的 datasets 字段不再覆盖资源目录，只保留方案、规则、权限及动作配置。

| 接口（相对 `/api/v1`）                              | 用途                             | 状态                                                  |
| --------------------------------------------------- | -------------------------------- | ----------------------------------------------------- |
| `GET /datasets?page&page_size`                      | 可访问的数据集目录，遍历全部分页 | 复用既有请求适配器；mock 已连通                       |
| `GET /datasets/:id/versions?page&page_size`         | 数据集的可读版本，遍历全部分页   | 新增前端契约；生产版本服务待联调                      |
| `GET /datasets/:id/versions/:versionId/samples?ids` | 固定版本样本读取                 | 复用既有接口；mock 增加发布版本读取，其他页面样式不变 |

版本列表使用统一 envelope，data 为 `PageResult<{ id, label, languages: string[] }>`；分页包含 items/total/page/pageSize/totalPages。语种为编码，名称由治理显示层统一转换。API 失败时不回退模块旧目录或 mock。

### 各模块业务接口

| 模块     | 已有适配接口                                                                                                                                  | 逻辑边界                                                                                     |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 数据处理 | `/data-governance/options?kind=governance-process`、`/data-governance/preview`、`/tasks`、`/tasks/:id`、`/kpis?kind=governance-process`       | 演示任务为只读快照；预览/创建仍请求真实后端，不伪造执行成功                                  |
| 价值分析 | `/data-governance/options?kind=governance-value`、`/data-governance/value-results/latest`、`/:id`、`/:id/samples`、统一 `/tasks`              | 读取保存结果；全量导出复用 samples 分页，不额外引入模型请求。mock 重新分析仍提示需要后端     |
| 异常治理 | `/data-governance/options?kind=governance-anomaly`、`/data-governance/anomaly-results/...`、`/data-governance/change-sets/...`、统一 `/tasks` | 20 项质量规则可查询；候选审核后进入修改集，校验后生成新版本。mock 校验修订、令牌及原版本不变 |

生产后端、版本持久化、权限与 LLM 执行尚未联调。本次完成的是前端适配、共享演示资源服务及契约测试；不能将这些描述为真实 LLM 或生产 API 已验通。浏览器不得接触模型密钥；后端仍需固定样本版本与标准、验证结构化返回、持久化证据和统计。
