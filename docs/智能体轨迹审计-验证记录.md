## 模式切换空白修复

用户反馈示例开关开启但仅显示标题和页签。浏览器按现有环境“初始真实模式 → 手动开启示例演示”复现了同样空白；之前直接以演示模式启动的验证未覆盖此路径。

原因是父容器用包含 demo 的 key 重建页面，同时子页面监听 demo 重新初始化共享 Pinia Store。旧组件卸载调用 dispose，取消了新组件刚发起的加载，并清空加载态，最终既无正文也无错误。

修复：只对 agent-traces 保持稳定组件 key，由子页面独立负责 API 和状态切换；其他合规页面的原有重建策略保持不变。切换时清空上一模式的对象 ID、上传队列和弹窗，防止把 Mock ID 送到真实接口；快速切换增加版本保护。增加未加载空态及重新加载按钮，避免静默空白。

回归脚本现在从真实模式启动，使用明确的 503 测试响应模拟后端未接入，验证手动切换后显示三张格式卡片；再执行三次 HTTP／Demo 往返，检查真实错误不回退假数据、重新开启演示后完整恢复。上述回归以及原上传、解析、定位、导出流程均通过。
