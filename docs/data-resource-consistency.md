# 数据资源统计一致性核查

## 修复依据

原统计 mock 单独写入阿拉伯语、“其他”、增长曲线、质量维度及使用排行，与资源目录无关联；资源 KPI 的 128 个数据集也不对应目录中的 6 个。筛选器使用另一套静态语种列表，mock 统计未应用筛选条件。现已移除这些无依据统计，并在资源目录中补充可聚合的演示记录；详细口径见 `data-resource-snapshot.txt`。

资源目录统一来自 `resource-catalog.ts`；数据治理目录和旧版通用数据集查询复用资源适配层。接入演示任务绑定目录中的 datasetId 和版本，不再仅靠不一致的任务名称建立关联。

## 统计口径

- 筛选选项汇总当前用户可访问的全部数据集标签并去重，不受本次筛选影响。
- 图表仅聚合应用筛选后的数据集。语种筛选表示“包含该语种的数据集”，多语数据集的其他语种仍计入该集合的标签统计。
- 语种、模态占比为标签出现次数占比；每个数据集的同一标签只计一次。当前没有逐语种样本计数，不能解释为样本条数占比。
- 阿拉伯语和“其他”只有目录实际包含对应标签才出现；未知编码不会自动合并为“其他”。展示名称由统一语种字典转换。
- 来源占比按数据集登记 storageGb 汇总；日期条件按数据集创建日期筛选。
- 接入成功率分母为已结束任务，排除运行中任务；空分母显示“—”。
- 演示数据为 6 个数据集，每个包含完整的 120 条演示样本。目录记录总数与样本集合一致。存储量和已有质量评分仍为目录中的演示元数据，不表示这 120 条演示文本的实测字节数。
- 综合质量分为选中数据集已保存评分的算术均值。质量维度、问题、使用次数、存储增量事件仅在有对应记录时聚合；没有记录显示缺失说明，不用零值或虚构曲线代替。
- 卡片、图表与统计导出共享 summary 快照和已应用条件；切换条件清空旧 summary，忽略过期响应。

## 接口清单

以下均已在前端适配层保留真实请求分支；当前独立 mock 演示不代表真实后端已联调。

| 接口 | 用途及状态 |
| --- | --- |
| GET `/data-resources/options` | 全量授权资源目录的语种、来源、模态选项；mock 已实现，真实服务待联调 |
| GET `/data-resources/summary` | 接收 view 与筛选条件，返回统一卡片、图表、统计口径和快照；mock 已实现，真实服务待联调 |
| GET `/datasets`、`/datasets/:id` | 数据集分页及详情；资源与治理共用目录契约 |
| GET `/datasets/:id/versions` | 治理读取固定版本及版本语种；真实服务待联调 |
| GET `/datasets/:id/versions/:versionId/samples` | 固定版本样本读取；mock 与治理共用样本 ID |
| GET `/tasks`（data_ingest） | 关联数据集的接入任务分页；mock 已实现 |
| POST/PATCH/DELETE `/datasets…` | 目录写入，始终请求真实后端，不伪造成功 |
| POST `/files`、`/tasks/execute` | 上传与接入执行，始终请求真实后端 |

待后端提供：质量维度明细、问题计数、使用审计计数和完整存储增量事件。汇总接口已保留相应字段。若要按样本统计语种占比，需另外提供按固定版本的语种样本计数及多语样本统计定义。

## 验证与边界

- 89 项测试通过，覆盖目录一致、语种选项与图表一致、筛选、空集合、演示快照计算、四页日环比渲染及真实接口参数。日环比的时点、公式、边界及接口字段见 `data-resource-snapshot.txt` 第 6 节。
- TypeScript 检查及生产构建通过。检查范围内 ESLint 无错误；未改动的 IngestTaskTable 有一条属性顺序警告。
- 本次修改前后全部 CSS 文件及其他模块 Vue 文件哈希一致。资源卡片上升、下降复用已有红色和绿色类，持平项按要求增加灰色内联颜色；共用卡片默认渲染行为由回归测试验证。
- 本次原生浏览器检查被工具自动策略校验中止（无法可靠识别 Windows 浏览器当前 URL）。已通过四页真实 Vue 组件的服务端渲染测试验证卡片文案、颜色类和持平灰色；未声称完成截图验收。
- 模型工作台独立的历史演示评估未重绑定资源，避免伪造历史样本关联；本核查不宣称这些历史结果已迁移。
